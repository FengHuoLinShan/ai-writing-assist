# 持久任务记录协议

当跨模块、长周期或高不确定性任务可能因上下文丢失而中断时启用本协议。入口为
`TASKS.md`，完整恢复记录放在 `tasks/`。简单问答和小修不建立记录。

恢复时先读索引和匹配任务，核对当前工作树、分支、HEAD、适用规则及未提交改动，再执行
记录的下一步。记录不是授权来源，当前用户指令优先。不得保存密钥或无必要的原始资料。

任务记录包含：目标与验收、授权与范围、上下文、进度、决策及理由、发现、验证、阻塞和
恢复快照（当前状态、一个可执行下一步）。重要决定、阶段通过、失败、交接和结束前更新；
不逐条抄录命令，不把任务进度写入全局入口文件。

只有全部验收通过才关闭任务；部分实现、静态测试或阶段完成不能替代总体验收。暂停时
保留开放状态并写明真实阻塞。Plan Mode/只读限制下只提供恢复快照，不写文件。
