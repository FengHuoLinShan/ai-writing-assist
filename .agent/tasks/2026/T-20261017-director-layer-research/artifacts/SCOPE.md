# 范围地图与方法（Phase 1）

日期：2026-10-17。独立范围审查：scope_challenge，修订后 PASS。

## 研究问题

1. 分尺度是否比通用导演更能帮助作者完成任务？不能把额外调用、更多资料或更长结果的收益算成分层收益。
2. 各尺度如何独立开局、得到首次可用结果、局部修改与离开恢复？
3. 中间的事件推演值得独立入口，还是作为其他尺度的展开操作即可？
4. 分层的错误传播、摘要损失、角色知识与候选事实污染如何控制？

## 修订的递归地图

| 尺度 | 一级分支 | 二级重点 |
| --- | --- | --- |
| 沙盘 | 行动主体 | 个人/家族/组织/制度，不以人数定义尺度 |
| 沙盘 | 物质条件 | 资源、人口、地理、交通、技术、魔法规则 |
| 沙盘 | 利益博弈 | 目标、联盟、威胁、承诺、内部意见 |
| 沙盘 | 变化传播 | 直接影响、连锁反应、延迟、阈值 |
| 沙盘 | 历史演化 | 阶段、路径依赖、转折、制度变化 |
| 沙盘 | 反事实 | 单条件变化、路线比较、敏感假设 |
| 沙盘 | 叙事利用 | 日常后果、可写矛盾、远景与留白 |
| 事件 | 触发条件 | 起点、资格、时空条件 |
| 事件 | 目标结构 | 公开诉求、隐藏动机、代价与底线 |

| 场景 | 场景任务 | 目标、阻力、体验、改变或保持 |

三种尺度作为待检验的观察方式，不预设三套产品。两个人二十年的关系可为宏观；十个势力的一次投票可为单场景。入口允许直接自然语言表达任务，不要求作者先做分类题。

## 横切维度

探索/指定结果/诊断；资料忠实/临时假设；单路/分歧；全局/角色视角；因果/象征表达；作者介入；一次回答/连续推演；保存、分支、恢复、引用与采用。研究编码可以多维，首屏配置不照搬这些维度。

每层同时研究非冲突用途：日常生活、规则压力测试、关系变化、探索发现、气氛意象、平静场景与余波。

## 方法与证据

- 应用型叙事综合，非 PRISMA 系统综述。公开中英文检索，以原始论文、作者原文、官方方法文档为主；经典方法允许早于近三年。
- 一级来源只支持各自研究任务结论；交互系统小样本研究不能证明中文长篇作者收益；形式规划不能证明文学质量。
- 本地代码证明实现边界；官方文档证明方法/公开行为；作者试用与文学盲评尚未执行，所有产品效用为待检验推论。
- 分支分工：宏观、事件、场景、人机交互、模型工程、项目代码基线；根代理负责来源整合、综合与报告。
- 三次反方检查：范围（本文件）、综合论证、最终报告。另做独立来源核验、编辑与归因/伦理检查。
- 收敛：分支具备任务、反例、证据状态；两轮针对漏项与反证的检索不改变一级地图和主要风险。来源耗尽不等于收敛，三层效果不能证明时明确保留未知。

## 关键反方问题

宏观是否只是更抽象地编造？事件模式是否增加菜单负担？场景表演卡是否过度填充？为作者分解是否转成让作者维护状态？不同模型预算下的收益是否被误归因？
