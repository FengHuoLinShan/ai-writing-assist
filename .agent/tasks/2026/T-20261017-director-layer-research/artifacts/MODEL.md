# 导演分层：模型与工程证据分支

核验日期：2026-10-17。范围：公开一手论文；未调用业务模型、测试或数据库。以下是设计证据和工程推论，不是当前运行时模型能力评测，也不是作者验收。

## 结论

分层有依据，但“分几层”与“每层更可靠”是两件事。缩小单次任务主要降低资料取用、同时满足约束和输出组织的负担；宏观抽象主要减少需要展开的状态与行动，帮助作者比较发展方向。后者仍可能要求跨时期、多主体、资源与制度因果判断，未必比一段对话容易。建议按问题选尺度，并分别限制时间跨度、活跃主体、依赖链和本轮产物。

## 对产品与工程的推论

**1. 把尺度与任务负荷分别控制。** 沙盘可只问“港口封锁后两周内，三个势力的首次应对”；事件可只问“谁有动机阻挠这次交接”；场景可只排演“一次试探与回应”。限制的是本轮推理边界，不强迫作者先走上层。宏观长跨度问题允许先给关键变量与条件分支，避免把一条顺口因果链包装成必然历史。此为工程推论，六篇论文没有直接验证这些入口设计。

**2. 摘要用于导航，条件保留来源。** “守卫因欠薪动摇”会丢失“部分守卫、已欠两月、军饷仍可能到达”等条件。建议随结果保留成立条件、未知项、反例、证据定位与时间范围，展开时重取原资料。这个例子是压缩风险演示；本分支没有直接的摘要忠实性实验，不能声称结构化字段足以消除损失。[长上下文研究](https://aclanthology.org/2024.tacl-1.9.pdf)支持资料利用须单独检查，未证明一种固定摘要格式最优。

**3. 上层决定要可撤销，下层应能报告冲突。** 上层输出分别标明作者锁定、已有事实和本轮假设。下层若找不到可信路径，返回需要重审的前提；不要为了完成大纲强造角色行为。[DOC](https://aclanthology.org/2023.acl-long.190.pdf)直接观察到大纲错误级联，因此增加层数同时增加交接检查的必要性。只更新被作者采用的分支，并标明依赖结果可能过时。

**4. 验证分成可计算约束与开放判断。** 时间先后、库存、位置、已死角色、明确记录的信息接触可建立确定性检查；判断人物会不会背叛、制度如何反应、冲突是否有趣，需要证据、替代解释与作者判断。确定性结算只保证已编码约束按规则执行；规则不完整或假设错误时，计算精确仍会得到错误因果。知识账本也只能约束已记录信息，不能证明人物心理可信。[FANToM](https://aclanthology.org/2023.emnlp-main.890.pdf)提供了知识边界的检查范式。

**5. 默认一次有边界的推演，额外调用要有具体职责。** 可选复核应检查“这个行动依据何种信息”“条件变化后结论是否还成立”，并取得独立资料或验证工具。不要仅把同一背景分给多个角色后反复投票。支持与反证同时存在：[Huang 等](https://proceedings.iclr.cc/paper_files/paper/2024/file/8b4add8b0aa8749d80a34ca5d941c355-Paper-Conference.pdf)比较等响应数量的辩论未见优势（未严格匹配 token/延迟成本），而[2026年研究](https://aclanthology.org/2026.acl-srw.1.pdf)在另一些配置中找到收益。部署判断应比较同预算的单次、独立候选与分工复核，并计算等待、重试和作者审阅负担。

## 检索与证据缺口

检索三组：Lost in the Middle / DOC / Re3；intrinsic self-correction / key condition verification；multi-agent equal compute / FANToM。打开出版页面后读上述六份 PDF，补读方法、限制及反证；未采用搜索摘要、媒体或论坛作为证据。Re3已定位，但未作为第七篇纳入矩阵。检索为定向叙述综述，不满足系统综述的穷尽性与双人筛选要求。

待验证：中文作者独立使用三种尺度的收益；宏观因果可信度；摘要条件保留率；层间误差传播；同预算多调用的净收益；长期人物状态维护。当前业务模型沿用项目约定 gpt-6-luna/max，本轮没有测其能力，不能据旧论文赋予它具体成功率。优先做有源资料、可回放的小样本作者任务比较，再决定层数与自动化程度。
