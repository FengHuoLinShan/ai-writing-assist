# 中观事件研究：独立使用与多方向细化

检索核验：2026-10-17。结论：有证据支持把事件分解为目标、信念、行动条件和后果，并由作者控制局部计划；没有直接证据证明“宏观—事件—场景”三层产品一定优于两层。以下产品建议均为推论。

## 七个探索分支

1. **起始与触发。** IPOCL把初始世界、作者期望结果与角色目标分开，动作含前提和效果；角色承诺也需要动机事件。这支持检查“为什么现在发生、什么条件使行动成为可能”，不只列时间顺序。[S1] **推论：**事件可从一句“继承人失踪”直接开局，先确认触发前状态、变化和当前未决问题；不知道的背景作为假设，不能强迫先做沙盘。

2. **公开目的、隐秘目标与代价。** 作者想要谈判破裂，不代表双方想谈崩；IPOCL正是针对作者目标替代角色动机的问题。[S1] **推论：**按需展开“想得到什么、对外声称什么、不能失去什么、愿付什么代价”。秘密目标仅向作者及知情角色开放。代价、目标冲突和价值排序不能伪装成现有规划算法已完整解决的能力；2018研究明确承认缺乏目标优先级。[S2]

3. **行动、反制与合作。** 2018研究允许角色计划包含其预期的他人行动，既可为合作，也可解释算计；预期不等于一定发生。[S2] **推论：**每步展示“行动意图—依赖条件—他人可能响应—状态变化”，响应允许帮助、妥协、拖延、退出和无行动。救援、修复关系、共同调查也适合事件推演，不应固定成敌我对抗。

4. **信息差、误解与揭示。** 信念模型区分事实和角色认为的事实，因此角色可以合理地尝试实际无法成功的计划；可信度不能只按全知视角判断。[S2] **推论：**分别问“谁知道、如何得知、何时得知、相信多少”，揭示应有可观察载体。作者知道的秘密不能自动成为角色行动依据；也无需让所有事件都靠误会推进。

5. **因果、偶然与失败路径。** 因果规划可检查后一步所需条件由何而来，但覆盖不到全部文学效果。[S1] **推论：**区分必要前提、促进因素和偶然触发；允许尝试失败、成功有代价和部分成功。改变结果时先找失效条件，再提出最小补桥；“搜索不到路径”只能表示当前约束或搜索失败，不能宣称文学上不可能。偶然可以制造麻烦，若靠偶然解围则提示作者评估铺垫与代价。

6. **余波与分支。** 戏剧管理研究显示，调整可选行动的呈现可提高进入指定分支的概率；这也说明“保留选项”不自动等于充分作者控制。[S3] **推论：**事件结果就地交付即时后果、延迟后果和仍未解决的债务；保存分支所改的条件及状态差异。向宏观外推或进入场景均为可选操作，不自动采用、不自动连跑。无需提前生成整棵树。

7. **三种意图分开。** 探索结局：在当前条件下比较少量不同因果路径；指定结局：固定终点，寻找不损害人物和规则的实现条件；诊断已有事件：检查原有因果与知识边界，先指出缺口再提供局部修法。**推论：**三者共享事件材料，但生成目标不同，应在开局允许一句话指定，避免把“检查我的事件”变成擅自改剧情。Re3与DOC支持计划、当前状态、局部生成和修订的协作机制，未直接验证这三种交互分类。[S4–S5]

## 是否应有独立事件模式

**推论：**应先确保“拿一个事件直接研究”的能力，再决定是否增加第三个同级入口。事件若包含跨地点、多轮行动与一段持续时间，具有区别于单场景的独立价值；若只是一个房间里的短谈判，场景模式的范围选择可能已足够。可先在统一导演入口提供“推演一件事”，不要求作者理解层级术语。

最小开局材料：事件/假设、涉及人物或群体、作者本次想解决的问题；时间跨度、结局、硬约束均可选，缺失关键条件再局部补问。结果应能单独保存、比较和继续，不要求产出正文。Dramatron的专业参与者研究支持共创用途，也记录了公式化等问题，其官方说明明确未按自主写完整作品来设计或评估。[S6]

## 反证、空白与后续判断

机制证据较强的是“区分作者与角色目标”“按角色信念行动”；独立事件入口、最佳跨度和信息表单数量缺乏直接证据。分层可能增加填写与切换负担，也可能让错误计划锁死后续。**推论：**比较两层界面与可独立进入的事件能力，使用单独开局、指定结局、既有事件诊断三类真实作者任务；观察获得可用方案的时间、改动量、动机/知识错误和是否愿意采用，不只评生成文本评分。

搜索记录：使用“narrative planning balancing plot character”“intentionality belief”“data-driven drama management”“DOC/Re3/Dramatron”等组合；保留作者、出版方原文与官方项目页，排除聚合摘要、论坛和把2014 arXiv上传年当IPOCL发表年的结果。误命中的ACL页面已排除；Dramatron HTML全文不可用，改用原始摘要与官方限制，未冒充阅读全文。
