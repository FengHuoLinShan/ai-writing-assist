    精确上下文与结果返回
    当前条目／截止场景 · 操作帮助 · 来源定位 · 修改回执
    验收：“这一条”准确，资料变化拒绝执行
  3. P1
    关系与整理路径
    对象内添加关系 · 本页范围说明 · 复用查漏专项
    验收：方向正确，不越过已采用资产保护
  4. P2
    布局与恢复对照验证
    顺序详情／连续浏览 · 图与列表 · 对象跨刷新草稿
    验收：任务完成、返回定位与恢复；先记录基线

工程检查

  • 未确认不写入
  • 过期／跨项目拒绝
  • 重复提交与部分失败可恢复
  • 草稿及秘密不泄漏

  • 找对对象与入口
  • 理解范围和状态
