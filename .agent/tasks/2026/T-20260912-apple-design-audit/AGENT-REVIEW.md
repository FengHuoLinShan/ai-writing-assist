# 独立视觉评审 · 当前桌面预览

日期：2026-09-12。对象：`http://localhost:8097/prototypes/redesign.html`。本轮只评审，不修改产品。业务尚未接回是已批准范围，不计为缺陷。

结论：现版有稳定底色、清楚的中文正文、适度色彩和基本控件一致性，属于完整的网页视觉样板；距离“一眼具有 Apple 原生创作产品的辨识度”仍有明显差距。主要差距是操作层级、排版密度、任务容器选择、内容配色和动效精工，不是再加更多模糊或 Apple 标志。

## 实际观察范围与证据

- 使用单独创建的后台 IAB tab，未操作用户原有交付 tab。当前视口截图为 1280×720。
- 实操：写作、专注进入/退出、专注内目录开关、AI→比较→Escape、主题切换、默认/加载/失败/冲突状态；概览、世界列表与人物详情、作品书架与新建对话框、账户与外观、互动故事列表与阅读。
- 用当前浏览器 CDP screencast 采集比较抽屉和普通新建对话框退出帧；采集不是 CSS 推断。时间信息在 `agent-evidence/frame-timing.json`，它是浏览器采帧时间，不是输入延迟或性能基准。
- 参考已安装 `frontend-design-ultimate` 的 SKILL、design-decisions、interaction-engineering：内容/操作/临时任务层级、真实中文排版、对象/空间/控制/状态连续性。Apple 多产品官方调查由主 Agent 独立完成并汇总；本报告不冒称独立看过全部官方产品。
- 未做全站性能基准、所有桌面宽度、减少动态效果设置或真实业务验收。浏览器交互和采帧覆盖如下问题，测试绿色不作为审美证据。

## 问题，按优先级排列

### 1. P1 · 抽屉退出期间布局塌成横排与单字竖列（实测缺陷）

位置：共享 `PreviewDialog.vue` 的抽屉形态，`redesign.css:54`。

复现：打开写作伙伴，选择“让这场相遇更有张力”，按 Escape。实际退出中间帧中，标题从顶部掉到面板中段，建议说明挤成单字竖列，页脚跑到右侧；塌陷内容透叠正文后才消失。当前帧 3 距首帧约 47ms、帧 7 约 114ms，均清楚可见。终态正常、焦点恢复正确，无法抵消中途的明显失精。

证据：`agent-evidence/drawer-exit-3.jpg`、`drawer-exit-7.jpg`、`drawer-exit-11.jpg`。普通新建对话框同样录帧，`dialog-exit-5.jpg`、`dialog-exit-8.jpg` 保持上下布局，没有同类塌陷。

源码解释：抽屉的 `flex-direction:column` 只在 `[open]` 下设置；close 移除属性后，离场过渡仍保留 display，布局方向却退回 row。建议将退出全过程必需的布局保持在抽屉基础样式，入/离场只改变呈现属性，再重录开关全过程。无需引入动效库。

### 2. P1 · 专注模式缺乏完整的控制与空间连续性（实测+审美判断）

位置：写作页目录/资料开关、专注退出；`WritingPreview.vue:14-23`、`RedesignApp.vue:52`、`redesign.css:53`。

复现：进入专注后，目录与资料栏已不可见，但对应按钮仍以开启状态呈现；点击目录按钮会改变按钮状态，画面中仍没有目录。点击左上“退出专注”后焦点落到 WebArea，不回到专注触发器。专注还同时改变正文栏宽、字号和顶部位置，眼睛需重新寻找同一句。既有录帧 `frame-00010.jpg` 可见侧栏收缩过程的残条及正文重排，本轮前后态也确认阅读面变化。

影响：按钮视觉状态不再表达眼前空间，专注操作不像自然收起工具而像更换另一张页面。建议专注只撤去控制层并保留正文阅读锚点；专注内隐藏不适用开关，或点击时明确退出专注并展开相应栏；恢复有效焦点。

### 3. P1 · AI建议和人物详情全部采用阻断模态，内容上下文被大面积模糊（实测+容器判断）

位置：写作伙伴、建议比较、世界人物详情。

观察：三个任务都打开同一右侧 430px 模态抽屉，左侧正文/资产列表全部模糊且不能操作。比较面板只能在窄栏中上下放“原工作稿”和“建议”，失去原正文上下文；人物卡片点击后也不保留可用的列表对照。

影响：模糊成为产品最强烈的视觉效果，但它在工作流中切断上下文。建议资料、AI候选优先使用非模态检查器；确有短任务边界的创建/确认才使用模态。比较时让正文与候选可同时读，避免以模糊制造“高级感”。

### 4. P1 · 写作默认画面控制层过多，正文没有成为明确主角（实测尺寸条件下的审美判断）

位置：写作默认 1280×720，证据 `agent-evidence/写作.png`。

观察：全站侧栏、章节侧栏、正文、资料栏同时占据四列；上方另有全站工具条和编辑工具条，下方正文状态条与演示条再次分层。正文面约占窗口不到一半。右侧提醒在首屏底端只露出上半部，人物信息在其下；多处 9–11px 辅助字与低权重标签密集存在。

影响：更接近浏览器后台工作台，视觉注意力在多套边界、标题、标签间来回。建议文档工作空间合并主要工具层，作品级导航按需展开；目录/检查器保留对象关系但减少重复标签。让长篇正文获得稳定、足够的宽度，重要提示在不滚动搜索的情况下可理解。

### 5. P2 · 多页重复“英文眉题＋抒情大标题＋副标题”，更像网站展示页（实测+审美判断）

位置：世界、作品、设置、互动故事首页。

观察：世界页的“A WORLD WORTH BELIEVING IN / 让你的世界，真实起来。”、设置页“MAKE YOURSELF AT HOME / 让创作空间，适合你。”长期占据页首大片空间。设置下方又有“舒服的空间，让灵感多停留一会儿”的第二层大标题；真正对象/偏好标题反而较弱。

影响：统一得像同一个营销页模板，用户每到一个高频任务都要越过宣传文案。建议高频工作页用简短对象名、紧邻工具和内容起始建立熟悉感；情绪标题留给概览或故事探索等确有收益的地方。

### 6. P2 · 色彩数量够，但层级仍由蓝紫渐变主导，高价值事项不够鲜明（实测+审美判断）

位置：创作概览，证据 `agent-evidence/创作概览.png`；世界分类与导航。

观察：最大、最饱和的色块是“继续故事”的蓝紫渐变和装饰星号；“等待你的决定”仍是白卡、黑数字、浅橙小图标，与普通统计差异很小。世界内容使用淡蓝/淡紫/淡青卡头，导航大多是灰线图标；“林舟/沈雁”同为人物却配不同色，颜色更像轮换装饰。冲突/失败提示本身已有可辨文字和色彩，值得保留。

影响：第一眼会读到通用 AI 产品风格，而不是鲜亮、功能清楚的创作系统。建议把强色集中于少量重要类别标题、图标与决定状态；内容颜色由作品封面/地图/人物意象承担，避免蓝紫为全站气氛兜底。不是把全站所有卡片涂得更艳。

### 7. P2 · 图标与箭头不是完整的同一视觉语言（实测+源码确认）

位置：编辑工具条、版本、导航、AI入口和普通详情链接；`WritingPreview.vue:23`。

观察：SVG线图标与 Unicode `◷`、`⛶`、`✦`、`↗`、`⌄` 混用；版本小钟与专注符号的视觉尺寸、笔画和基线明显不同。大量内部详情、建议和普通跳转统一用右上箭头，空间语义不清。

影响：近看像网页拼出的控件，削弱用户要求的精工辨识度。建议以现有 SVG 图标体系补齐缺项并光学校准；展开、前进、外部打开采用各自明确语义。不需要为了像 Apple 引入品牌标志。

### 8. P2 · 世界素材依赖重复巨型单字卡头，内容视觉辨识度不足（实测+审美判断）

位置：世界资料页，证据 `agent-evidence/人物与世界.png`。

观察：人物、地点、物品、规则、组织使用几乎相同的巨大渐变卡头＋单汉字＋同心弧线；一个卡头耗掉不少高度，却没有展示比文字列表更多的对象信息。

影响：看到的是组件模板而非人物/世界。作品书架已有区别清楚的封面构图，是更好的方向。建议有图像价值的对象提供认真设计的示意素材；无素材时用精细列表、紧凑头像或小型类别符号，不以同一大装饰头覆盖所有对象。

### 9. P2 · 沉浸阅读仍保留作者工具，情境切换未完成（实测+审美判断）

位置：互动故事→“回到白沙港”进入阅读。

观察：作者侧栏确实退出，但顶部仍是全局查找、主题和紫色“写作伙伴”；点击伙伴仍出现“让这场相遇更有张力”等作者编辑提示。读者内容本身版面平静，但顶部工作语境属于作者后台。

影响：沉浸页像在同一个后台上隐藏了侧栏，尚未获得独立阅读产品的视觉身份。建议读者控制层只承担返回、阅读设置、进度、角色/线索；作者工具在作者情境中出现。此项评价可见控件组织，不要求接回任何业务。

### 10. P2 · 新建对话框主次动作分散，演示框架压过产品组件（实测+审美判断）

位置：作品→新建作品。

观察：表单底部左边是蓝色“预览创建反馈”和“取消”，最下方独立灰色页脚右边又有“完成预览”，右上还有关闭。对话框最显眼的页脚动作不是当前表单主动作，所有弹层还复用“设计预览”眉题与固定页脚。

影响：同一组件有两套结束语义，呈现的是组件演示台而非完整产品设计。建议保留全局明确的演示标记，但让任务对话框只有一组符合当前任务的主要/次要动作；展示状态的入口放在统一预览控制处。

## 可以保留的部分

- 正文白纸/深炭灰底色稳定；中文正文行距和段落节奏比信息面板更成熟，不需要给正文加玻璃。
- 浅深色都有独立前景、背景和提示配色，候选/完成/风险并不只靠颜色表达。
- 作品书架的三种封面有各自构图与色调，内容能承担视觉表达；值得继续精修。
- 分段选择、侧栏选中和按钮家族已有基本一致性；模态 Escape 关闭与焦点回触发器实测正确。
- 普通对话框退出布局保持稳定，抽屉缺陷可以在共享样式处最小修正。

## 建议次序

先修抽屉离场布局和专注控件/焦点；再确立文档工具层、检查器与阅读控制层；之后统一字级/图标，删除高频页过量标题，以重要类别和内容素材重新组织鲜亮色彩。不要先全站增加玻璃、弹簧、阴影或系统装饰。

本评审保留主观判断与实测缺陷的区别。未声称用户已认可审美，未改动业务或预览代码。
