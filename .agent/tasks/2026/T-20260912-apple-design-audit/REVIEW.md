# Apple 多产品对照：当前预览尚未达到目标

**结论：当前版本是完整、较整洁的网页视觉样板，尚不能让人第一眼认为它拥有 Apple 原生产品的设计完成度。**
关键差距集中在文档工作区的组织、文字与图标的精工、颜色与内容的关系，以及动效中间态。
继续增加蓝紫渐变、圆角或模糊，不会解决这些差距。

下一版的设计定位应明确为：**像 Apple 为长篇作者设计的文档应用。** 写作以 Pages / Notes 为主参照，
内容浏览借鉴 Music / Photos，提醒借鉴 Reminders，阅读借鉴 Books；保留 NovelCraft 品牌。
“一眼像 Apple”是待视觉评审验证的目标，本报告不将主观判断伪装成用户测试结果。

## 已确认的问题与优先级

P1表示应在下一轮视觉交付前优先解决；P2表示明显影响Apple辨识度的精修项。
“审美判断”不是客观故障，“实测缺陷”也不应被整体截图的整洁程度掩盖。

| 优先级 | 问题与具体证据 | 修改方向 |
|---|---|---|
| **P1 / 实测** | **抽屉关闭布局塌陷。** AI→建议比较→Escape，本轮47–114ms中间帧出现标题下坠、说明单字竖列和页脚横排。普通新建dialog对照正常。 | 保持抽屉从打开到关闭整个过程的布局不变量；基础布局不能只挂在`[open]`上。修改共享样式即可，无需新动效库。 |
| **P1 / 实测** | **专注状态与可见空间不符。** 隐藏的目录/资料开关仍显示开启，点击只改状态而不出现面板；退出专注焦点落到页面，正文还同时改字号和宽度。 | 专注只撤去工具，保留阅读锚点；隐藏不适用开关，或点击时明确退出专注并打开目标栏；恢复有效焦点。 |
| **P1 / 设计判断** | **写作控制层过多。** 全站导航＋目录＋正文＋资料四列，顶部两层工具条，底部两层状态条；1280窗口中正文不到半屏。 | 把全站切换收进作品/导航入口，保留目录—正文—上下文；合并文档工具条与状态说明，底部演示控制改为按需展开但保留演示身份。 |
| **P1 / 设计判断** | **资料、AI、比较一律使用阻断模态。** 背景原文模糊，430px窄栏内上下比较，破坏编辑上下文。 | 资料与AI候选使用非模态检查器；比较提供同时可读的两份文本；只将创建、危险确认等短任务交给模态。 |
| **P2 / 设计判断** | **高频页面套用了营销页标题模板。** 多页重复英文眉题、抒情标题、副标题；设置页甚至再来一层大标题。 | 对象名与内容先出现。标题改为“人物与世界”“作品”“外观”等简短任务语言；情绪文案集中在欢迎与故事探索。 |
| **P2 / 设计判断** | **颜色角色正确，强调力量失衡。** 最大色块是蓝紫渐变装饰，“等待决定”却只是白卡＋浅橙小图标。 | 让重点类别符号、数量和选中状态更鲜亮；正文与一般容器保持中性。单独设计内容配色，不按卡片序号轮换粉彩。 |
| **P2 / 实测与判断** | **图标混用且空间语义重复。** SVG与`◷/⛶/✦/↗/⌄`混合，笔画与基线不齐；内部详情大量使用外开箭头。 | 补齐现有SVG图标，统一光学重量与基线；区分返回、展开、下一层和外部打开，不靠系统Logo补原生感。 |
| **P2 / 设计判断** | **重复巨字卡头的素材完成度不足。** 人物/地点/规则都用同一大字、粉彩背景与同心弧线。 | 有视觉价值的对象用认真设计的内容素材；缺少素材时退回精细列表、紧凑头像与类别符号。保留作品书架已有的独立构图。 |
| **P2 / 实测与判断** | **阅读页仍保留作者工作语境。** 写作伙伴继续展示“让相遇更有张力”等作者编辑提示。 | 读者顶部只保留返回、阅读外观、进度、人物与线索；通过控制层完成情境切换。 |

## 下一版具体设计方向

### 1. 先把写作做成文档应用

顶部只保留当前作品/章节、文档操作、资料开关与一个清楚的AI入口；全站功能仍可到达，
但不占用一整列常驻导航。目录与检查器按需出现，中央正文维持稳定的字号和阅读位置。
先完成这一屏的浅色、深色、普通、专注、资料展开和建议比较，再把相同工具语言用于其他页面。

### 2. 用光学细节建立熟悉感

主导航/常用操作以可读的12–13px起步，中文阅读正文从17–18px试排；这是本项目建议，不是Apple的通用硬标准。
9–10px仅留给确属次要的短元数据，不能用字号缩小弥补控制层过多。
补齐SVG图标，统一轮廓、重心、基线、命中区域；建立内容面、浮层和控件的圆角关系。

### 3. 让鲜亮色彩有明确归属

采用“中性画布＋明确主色＋内容色彩＋强语义提醒”。
蓝色操作、紫色建议、绿色完成、橙色待决定、红色阻断继续保留。
待决定类别使用饱和小图标/明显标题/数量，重要事项可有一块足够醒目的提示，普通统计保持安静。
作品封面、地图与人物意象承担情绪丰富度，取消每页都依靠蓝紫大渐变撑场面的做法。

### 4. 动效表达来去关系

短选择在触发器附近展开；检查器从所在侧进入；需要确认的任务在稳定对话框内完成。
正文、浮层内部排版在过渡期间保持稳定。来回快速切换不出现残条、单字竖列、跳页或无效按钮状态。
材质只有在内容实际经过控制层下方时才承担通透效果；无透明时仍能看清层级。
不会把全站模糊或统一弹簧视为完成标准。

## 视觉验收方式

- 同一窗口下并排看Pages/Notes参考与写作样板，先检查工具层、文档重心、控制密度，再看色彩和阴影。
- 原速看打开、关闭、中途反向，再慢放查中间帧。不能只检查动画前后的截图。
- 保留浅深色、减少动态效果、键盘路径；不重新引入截图像素、DOM或CSS写法门禁。
- 用虚构作品和长中文内容做视觉验收。建议在精修后进行5秒首印象评审：隐藏品牌文案，请熟悉Apple产品的人自由描述感受，记录“像Apple原生应用”的识别是否自然出现。目前尚未进行此类用户验证。
- 业务尚未接回属于已批准范围，不作为本次缺陷；也不以业务回归通过替代设计验收。
