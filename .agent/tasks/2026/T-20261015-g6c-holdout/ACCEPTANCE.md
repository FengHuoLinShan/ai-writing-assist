旧 G6b 自测 30/30 与修复候选的开发审查 32/32 直接按真实证据及当前规则核验，没有伪造新数据集的校准收据。

16 个资料族、32 条题（可答/应拒答各 16），与既有 Ask World baselines 及 refusal 开发集的
family、问题和来源正文均不重复。覆盖六层：冲突、单来源、互补来源、近似无答案、范围排除、
夹入指令。采用新的上下文、条件和提问组合，既有修复版在这些材料构造之前已固定。
这些是合成留出材料；未参与调参不代表由独立真人出题，也不代表覆盖真实作者分布。

原版与修复版各生成一次，同题配对，随机交错运行，最多两个生成请求并发。原版从封存的真实
服务源码载入，核对两份源码仅有已批准的 Prompt 差异；当前生产 Prompt 不来回修改。
两版均经 owner 验证的 Project facade 使用 Luna/max，没有替换传输、伪造连接或切换 API。
评分固定独立 Sol/xhigh，沿用已校准 rubric；按资料族拆为两批，各包含混排后的两版输出，
使用中性编号，评分器看不到版本名称或改动目标。每批只调用一次。

当前 G6c 是用户显式授权的一次性入口，调用前须验证自身 FREEZE_CONFIG 和父校准证据，
整体及逐题材料哈希独占锁阻止整套或子集误重发。没有解除普通 evaluator 的全局暂停守卫。
格式/引用修复保留原生产调用链行为，其每笔原生尝试也须保留，不能拿成功结果覆盖先前尝试。

## 冻结的验收标准

- 64 份输出完整且评分有效，参考全部接受、无歧义或缺失；冻结配置、当前连接和旧证据不漂移。
- 修复版在 16 条可答题的过度拒答严格少于原版；原版为零则改善效果不可判定。
- 修复版过拒答率不高于 5%（当前分母要求 0/16），语义通过至少 95%（至少 31/32），且总数不低于原版。
- 修复版在应拒答题上错误作答、无依据主张、答案与主张矛盾均为零且不多于原版。
- 修复版冲突处理失败为零且不多于原版。缺失、失败与 unknown 不从分母移除。

另报告配对改善/退步和可答题的精确双侧符号检验，作描述性证据，不追加为事后门禁。
同一资料族两条题相关，不能按 32 个独立资料族推导总体发生率。
冻结留出启动即消耗；不按结果改参考、Prompt、评分或验收标准，不再重跑。

### 保留的失败与指标解释

修复版保留 1 条综合失败 `ask-g6c-tin-road-draft-positive`。两版都分别引用两个草案，
主张受来源支持，原始教师均判 pass，但 uncertainty 为空。既有确定性冲突条件同时要求
引用覆盖与 uncertainty 非空，因此两版均记 `conflict_sources_not_covered`；并非实际漏引或幻觉。
不更正标签、输出或门禁追认全通过，仍按冻结规则保留 fail。

原版另有 2 条过拒答（守钥人、值守起点），均在修复版得到并列引用回答；还有 1 条同类
uncertainty 为空的耗材冲突综合失败，在修复版通过。全部 5 条两版失败记录保留。

[补充审计](artifacts/holdout-audit-v1.json) 区分原始教师与综合门：原始教师/确定性共有 3 条分歧，
真实判定一致为 61/64。原账本的 `deterministic_teacher_agreement=1.0` 是既有汇总程序比较
“已纳入确定性前置门的综合状态”，不能解释为原始教师与确定性零分歧；该原字段保持原样，
本说明与审计单列差异，不改冻结评分、统计公式或结果。
