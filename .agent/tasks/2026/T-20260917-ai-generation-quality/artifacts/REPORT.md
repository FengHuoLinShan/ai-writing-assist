## 真实失败推动的共性修复

- **生成与审查看到不同资料**：World 使用完整的已过滤参考与原作者对话，Story 带入场景、目标和附加要求，RP 带入最新用户约束；取消三域在治理层再次截断 24K 字符。相同权威/生成资料只渲染一次，内容不裁掉。
- **首次输出猜 schema，返修没原稿**：结构化客户端首次请求就传实际 Pydantic schema；World/Story 返修接收原输出与同一参考。首次确定性校验失败和知识问题共用初次一次返修额度。
- **省略内容被清空，返修丢掉新实体**：World 区分省略与显式空值，返修合并上一提案；审查、保存使用相同 ID 空间，覆盖 knowledge layers/known_by；固定分类名不再可编辑。有效内容与历史保留。
- **已保存通知变成新任务**：成果通知留在历史与 checkpoint，但不再被编译成作者指令。候选编译不凭空要求作者重新决定已经明确的内容。
- **输出被误放行或无可用返修**：世界聊天有一次知识返修；精细设计反例返修后的知识复审有一次定向修正，失败关闭，终审不再开循环。恢复状态 v3 保存修正阶段，重排不重复消耗。
- **审查把所有创作都当无来源，或把硬错误当小瑕疵**：明确创作新增许可、抽取/问答的来源限制、人物知识与数量约束。逐段检查实际行动，不因前文复述正确规则而放过后文违背。影响方案可执行性的矛盾计算不能用“候选近似”降级。
- **RP 凭空补装备**：故事 Prompt v8 明确持有物、数量和能力限制，审查另列最新用户要求。

没有增加新运行时框架、自治多 Agent 或外部服务。新增运行的请求额度覆盖有界修正，旧运行的冻结额度不自动扩充；普通保存/采用仍由作者决定。

## 结论边界

三项明确缺陷已修复，真实输出暴露的跨域输入、返修与审查问题也已落到代码和回归。
本轮不证明所有生成内容都能直接采用，也不证明长篇文学质量、多个模型或所有入口稳定达标。
图片生成、地图图像、多轮长篇与其他provider未做真实模型质量验收；浏览器与生产数据库未做本轮验收。
这些开发样本在修复时重复使用，不能作为未见样本盲测。开放问题会继续交给作者；不将“模型审查PASS”等同“真实作者觉得可用”。


## 尚未达到的质量目标

不能宣称“本项目所有AI输出已经稳定可用”。已证明模型审查会误判：最早的生命运输、装备、
私人水源和算术错误都有自动PASS；相应精确负例现已进入真实回归，但这不证明不会出现新形式。

最后总纲V3的主债务表6+3.6+5.4+10=25，现金4.2+2.6+1.4+1.1=9.3，卖出方案18-15=3、
剩余贷款7均能对上；留下方案先付8.6另补0.64后应余0.06万，结尾却只重述“支出8.6万、现金清零”。
这份稿的资金表与结尾表达尚未完全一致，不能把自动审查PASS当成定量内容合格证明。
此外，“可随时撤回退出协议”与“失去无条件退路”的关系还需要作者澄清。

工程缺陷与本轮证实的输入/返修/权限问题已经修复；生成文学内容仍是可编辑候选。
进一步关闭质量目标，需要用新场景检验误放行率，并为依赖数量的内容选择可靠的独立核算方案，
或在同样资料上比较其他账户模型。没有通过再堆提示词、删负例、无限重试或自动采用来冒充达标。
所有本轮测试进程已结束；未安排后台自动付费重跑。
