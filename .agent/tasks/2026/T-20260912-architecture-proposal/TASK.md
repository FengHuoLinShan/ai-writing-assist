## 决策、发现与失败

- 主栈暂无重选依据；优先检查恢复语义、schema 一致性、实际生产路径覆盖和资料恢复。
- 对象图片无异地备份是 ADR-0014 明确接受的取舍，须列为产品资产价值增长后的重新决策项，而非宣称违反现行设计。
- D8a-1 原称六个草稿前缀未清理，实际三个 `novel_outline_*` 已被 `novel_` 覆盖；用生产函数和纯内存合成 storage 验证，仅另外三个遗漏。不改原报告，在提案明确纠正。
- D3b-2 应先裁定事件/投影语义，不能只作为性能待测项。历史有类型化事件的库不能被概括为所有投影恒空。
- 数据库子代理的 world library 漂移、四类同项目关联缺复合 FK、索引仅按名验证均经主 Agent 对照代码；不采纳其“已有正确 FK 的库仍需修复迁移”概括，也不把普通项目 FK 当成同项目父子关系约束。
- schema parity repair 未发现确定性破坏，不列缺陷；JSON/JSONB 等价比较作为取舍，重复 Scene 索引归低优先级按负载裁定。
