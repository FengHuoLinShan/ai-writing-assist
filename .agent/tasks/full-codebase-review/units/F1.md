- 风险：中——指纹兼容是硬约束；变体 B 的调用点（imports 别名关系任务的 str payload）须保留 passthrough 语义。
- 依赖：F2 认领权威位置；涉及 imports/story/world/writing/llm 多槽位的调用点迁移，宜作跨槽位批次。

- **app 组合根**（`backend/app/main.py`）：模块导入即执行 `register_container_services()`（bootstrap.py:200，先导 13 个 ORM models 模块注册 metadata）+ `register_task_handlers()`（task_runtime.py，11 个任务模块字面量 import：assistant/imports/map_atlas/interaction/outline_state/project/indexing/focused_tasks/story/world/writing tasks）。

### 异常映射现状
- `DomainError(code, message=detail, status_code, context)` ← NotFoundError 404 / ConflictError 409 / ValidationError 400（parse_uuid 用其抛 422）。唯一全局 handler 在 main.py:559：响应体 `{error, detail, message, status_code[, context]}`；日志仅 method/route/status/novel_id，不含异常值。
- `RequestValidationError` → 422，递归剥离 `input` 键（不回显请求值）。
- 未捕获异常双路稳定 500 JSON（`error=InternalServerError`）：`@app.exception_handler(Exception)`（日志：类型名+受限栈 `file:line:func`，无异常值）+ `ServerErrorMiddleware` 同 handler（使外层短路响应也获得统一安全头）。
- debug_api：非 public 才注册 router + handler 级 `app_env==production → 404` 双层；`_redact` 剥离敏感键（api key/authorization/token/password/secret/credential）与 sk-/Bearer 值模式。
- 配置校验全部 fail-closed 于 import/app 创建时：CORS 通配仅本地环境、closed_test 外环境强制 APP_ACCESS_TOKEN、public 模式强制 DEBUG=false/密钥≥32/HTTPS/SMTP 完整、HTTP 限流非本地环境必须>0。
- `Settings` 为 frozen dataclass + `lru_cache get_settings()`；`llm_api_key/llm_base_url/llm_model/llm_timeout` 为遗留字段但仍有消费者（scripts/doctor.py:640-642、infrastructure/llm/health.py:327-347、providers.py:142、imports 超时计算）——**不构成死代码**；业务 LLM profile 权威在 DB（owner 账户连接），符合 AGENTS 运行时 LLM 条款。
- 边界观察：shared.utils → core.errors 单向 import，core.crud → shared.{utils,constants} 单向 import；包级 core↔shared 互达但模块级无环，现状无导入问题（新增 core 模块 import shared 时注意保持模块级无环）。
