所有查看页面的手动编辑应该怎么做？

你要求“所有查看页面都要方便手动编辑”。关键是编辑入口要强，但不能让查看页到处变成复杂表单。

A. Inline Quick Edit / 原地快改
地图查看中

点击人物标记
直接弹出小编辑器：位置 / Scene 范围 / 关系
沈砚

位置：洛阳外城
Scene：12 - 14
状态：canonical

保存 / 转候选 / 查看来源

原地快改

最快，适合高频修正位置、人物、事件。但复杂对象容易把地图弹层做重。

B. Universal Inspector / 统一检查器
图层 / 时间 / 搜索
地图或其他查看页
右侧检查器

概览
地图事实
来源证据
冲突与建议

快速保存 / 打开完整编辑

统一检查器

所有页面点击对象都打开同一个右侧面板，能编辑地图事实、查看来源、处理 AI 候选。密度和一致性最好。

C. Edit Tray + Command / 编辑托盘
任意查看页

多选人物、地点、事件、势力
底部编辑托盘：移动到地图格 / 绑定 Scene / 标记势力影响 / 批量确认 AI 建议 / 批量回滚

编辑托盘

适合批量操作和高级作者，但日常单对象编辑不如右侧检查器直观。
