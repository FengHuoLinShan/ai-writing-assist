第七节修订：支撑超级地图的模块增强计划

地图超级形态不是只改 map。imports、memory、outline、context、world 都需要提供更稳定的结构化输入。

Module Enhancement Plan for World Dynamics Map
imports
深度导入输出 typed observations
位置/状态/边界/影响域候选
每条候选带来源证据和置信度

outline
剧情线、主线危机、Scene 阶段
当前焦点和主次权重
危机与 Scene/地点/人物关联
memory
delta_log 类型化
快照暴露地图可消费历史
支持按对象/时间查询变化
支持 stale/rebuild 影响地图动态

context
来源证据快照
LLM 映射审计
给检查器展示引用摘要
world
对象强地点关联
角色知识边界和状态维度
名称/时间优先展示契约

world/map
MapObservation / MapFact
MapDelta / WorldDynamic
自动布局和避让
三视图和统一检查器

增强原则

1

每个模块只增强自己的领域事实

outline 不写地图，imports 不做地图布局，memory 不拥有地图 UI。

2

world/map 统一归一化

所有输入最终由 map 转成地图事实、地图差分、动态事件和布局结果。

3

分阶段升级

先把现有 delta/snapshot 接进地图，再扩展 typed observation 和高级动态。
