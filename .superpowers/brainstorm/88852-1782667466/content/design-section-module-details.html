第七节详细版：各模块增强细节

每个模块只增强自己的领域事实；world/map 统一归一化为地图事实、动态事件和可视化布局。

Module Enhancement Matrix
imports
typed observations: 位置、状态、边界、危机、语义关联
evidence: quote / scene / context snapshot / confidence

memory
typed delta 查询：对象 + 时间 + 动态类型
snapshot/rebuild 影响地图动态重算

outline
主线、危机、Scene 阶段、焦点权重
剧情线与人物/地点/组织/事件关联
context
检查器证据摘要
快照健康和来源可追踪性

world
名称优先展示契约
对象状态维度、地点强关联、知识边界

world/map
MapObservation / MapFact / MapDelta / WorldDynamic
避让布局、三视图、检查器、电影化播放
