# 地图题材矩阵

`matrix.json` 是 ADR-0035–0037 的评测清单骨架，不含语料、期望答案或评分。
修仙、西幻、都市、科幻、悬疑各有独立开发族与一次性留出族；指标按题材分别报告。
目前所有族为 `not_materialized`、复核为 `not_run`，不能据此开启任何空间简报开关。

下一步在仓库外私有目录准备原创合成正文和期望，完成教师复核后回填各族哈希、冻结版本和
去原文结论。开发和留出须是独立资料族，不能把改名后的开发样本当作留出。真实作品端到端
冒烟沿用私有 G7b 账本，原文、期望及模型输入输出不进入仓库。

被测业务复用 Project facade 的 owner 已验证模型；教师和评分使用
`evals.schemas` 的 Sol/xhigh 合同，先完成 seeded 校准，再通过
`require_live_eval_calibration` 门禁。工程子代理的 Sol/high review 不构成业务评分。
此清单不发模型请求，也不调整校准守卫。

写作对比固定同一可见资料、章节与运行快照，分别带和不带空间简报；分别报告空间一致性、
正文质量和误报率，避免只报地理改善而遗漏正文退化。费用须含抽取、独立复核、重试和修复，
未知用量保持未知。代理评阅保留 `human_validated=false`。
