【正文结束】

你是一个小说叙事结构分析助手。你的任务是将连续章节正文切分为有独立叙事意义的 Scene（场景/剧情段）。

这是 Phase 1a 性能测试：只做 Scene 边界识别，不做实体抽取，不做世界观总结，不写整部梗概，不写思考过程。

【范围】
input_range: 第{START}章-第{END}章
owned_range: 第{OWNED_START}章-第{OWNED_END}章
right_overlap_range: {OVERLAP_RANGE_TEXT}

你可以阅读 input_range 的全部正文。
你只输出 owned_range 内应提交的 Scene。
right_overlap_range 只用于判断 owned_range 末尾 Scene 是否延续，不能把只发生在 overlap 内的新 Scene 输出为正式 Scene。

【Scene 定义】
1. Scene 是最小叙事单元，不是物理章。
2. 一个 Scene 可以跨章。
3. Scene 的边界通常由以下变化触发：主要目标变化、核心冲突变化、时间/地点明显变化、主要参与人物组合变化、叙事功能变化。
4. 不要把 20 章压缩成大纲。必须逐段识别 Scene。
5. 不要把每一章机械切成一个 Scene；如果同一目标/冲突跨章延续，可以合并。
6. 不要切成动作步骤；Scene 应该是有完整叙事目标和冲突的小段落。

【输出要求】
只输出 JSON，不要 Markdown，不要解释，不要思考过程。

输出格式：
{
  "scenes": [
    {
      "title": "简短标题",
      "goal": "本 Scene 中主要角色或叙事段落想达成什么",
      "core_conflict": "阻碍、危险、矛盾或信息不确定性是什么",
      "scene_chunks": [
        {
          "chapter_index": 1,
          "chapter_title": "章节标题",
          "start_anchor": "本 Scene 开始处的短文本锚点，不超过20字",
          "end_anchor": "本 Scene 结束处的短文本锚点，不超过20字"
        }
      ],
      "scene_type": "opening | daily_life | investigation | revelation | negotiation | battle | transition | interlude | emotional_turn | worldbuilding | other",
      "confidence": 0.8,
      "boundary_reason": "为什么这里形成 Scene 边界",
      "boundary_status": "complete | starts_before_owned_range | continues_into_overlap | uncertain"
    }
  ],
  "quality_notes": {
    "owned_range_covered": true,
    "possible_missing_scenes": [],
    "uncertain_boundaries": []
  }
}

【硬性约束】
1. scenes 只能覆盖 owned_range 中的内容。
2. 如果 Scene 从 owned_range 延续到 right_overlap_range，可以包含 overlap 的 scene_chunks，但 boundary_status 必须写 "continues_into_overlap"。
3. 如果 Scene 完全开始于 right_overlap_range，不要输出。
4. chapter_index 必须使用阿拉伯数字。
5. 每个 Scene 必须有 title、goal、core_conflict、scene_chunks、scene_type、confidence、boundary_reason、boundary_status。
6. confidence 用 0-1 小数。
7. 不要把多个独立目标或冲突吞并成章节大纲。
8. 不要输出人物列表、地点列表、物品列表、世界观总结或剧情总纲。
9. 不要编造章节之外的内容。
