# Superpowers 工作记录分类

本目录保存设计与交付过程中的工作记录，不是当前系统架构、数据库 schema 或产品需求的
权威来源。当前状态以根目录 `docs/00_整体设计.md`、`docs/01_数据库设计.md`、模块
README、ORM `models.py` 与 Alembic migration 为准。

## `plans/` — 历史交付计划

`plans/` 中按日期命名的文件是当时的实施拆解和验收意图。它们包括 2026-06 至
2026-07-08 的计划，统一分类为 **历史交付计划**：

- 不因后续代码变化回写或修订计划正文。
- 不把计划中的模块、Prompt、表、路由或测试当作当前事实。
- 需要追溯某次决策时可引用其日期和文件名；要判断今天的状态，回到活跃设计文档和代码。
- 新计划应只服务尚未完成的明确工作；完成后同样留在本目录，成为历史记录。

## 其他工作记录

| 目录 | 分类 | 使用方式 |
|---|---|---|
| `specs/` | 设计快照 | 仅在被活跃 ADR、PRD 或模块文档引用时作为背景；不自动覆盖当前设计。 |
| `reports/` | 审计与 QA 记录 | 用于追溯发现和验证范围，不代表当前缺陷或实现状态。 |
| `acceptance/` | 验收基线与历史结果 | 可用于回归对照；新的验收应新增带日期的记录。 |
