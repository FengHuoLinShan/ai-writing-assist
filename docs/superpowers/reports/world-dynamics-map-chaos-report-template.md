## 缺陷分级

### P0 阻断

- 地图入口不可用。
- 默认总控台不存在。
- 对象无法点击或无法编辑。
- AI 候选直接污染正式事实。
- 地图事实没有来源和状态。
- 三视图事实不一致且会导致数据错误。

### P1 严重

- 检查器信息不完整。
- 批量修改不可用。
- 高密度地图明显重叠，影响阅读。
- 空间连续性风险无法识别。
- 回滚或忽略路径缺失。
- 默认展示技术 ID。

### P2 体验问题

- 动效干扰阅读。
- 焦点切换不稳定。
- 图层控制不清晰。
- 语义气泡遮挡地图。
- 低动效模式缺失。
- 电影化播放内容不足。
