# 写作页第三阶段范围讨论稿

## 背景

写作页前两个阶段已经覆盖核心写作工作台和冲突检查能力：

- Scene 树、正文编辑、版本历史和右侧 Scene 驾驶舱已经形成主工作区。
- `剧情设定冲突检查` 已包含规则检查、历史记录、详情弹窗、AI 软冲突判断和 AI 修复建议。
- 右侧 Scene 驾驶舱已支持本地拖拽排序和高度不足时折叠后段模块。

第三阶段不应重复实现上述能力。本轮选择 **B：AI 写作工具胶囊成型** 为主轴；C 的独立 Scene 整理工作台先不动，作为后续阶段方向保留。

## 当前章节卡与 Scene 卡关系

当前系统应按以下关系理解：

- **章节**是正文的物理容器，对应 `writing_drafts.chapter_index` 和正文内容。
- **Scene 卡**是当前权威结构单元，对应 `scenes` 表。Scene 通过 `chapter_ids` 和 `scene_chunks` 映射到一个或多个章节，承载目标、核心冲突、情感节奏、必须发生和禁止发生等字段。
- **章节卡 / ChapterCard**主要是历史概念和兼容上下文。`chapter_cards.scene_cards` 不再是权威来源；当前权威来源是 `scenes` 表。
- 现有“AI 提取章节卡”入口在产品语义上应理解为“从章节正文中提取 / 更新 Scene 卡字段”，不是恢复独立 ChapterCard 工作流。

因此，第三阶段讨论时不要把“章节卡”作为新的主对象。若需要整理章节，应围绕 Scene 与章节正文的映射、对齐、复核和移动来设计。

## 选择轴

### A. 个性化 Scene 驾驶舱

把当前本地排序升级为完整偏好系统：

- 跨端同步驾驶舱模块顺序。
- 模块显示 / 隐藏开关。
- 按写作模式切换预设，例如“冲突优先”“情感优先”“地图连续性优先”。

适合解决长期使用体验，但对主流程提升偏温和。它建立在已有驾驶舱能力之上，不是第三阶段唯一高价值方向。

### B. AI 写作工具胶囊成型

把当前 `AI 工具 · 待定` 变成围绕光标和选中文本的高频动作：

- 续写当前段。
- 局部改写。
- 补强冲突。
- 补情绪 / 动作。
- 解释当前段与 Scene 目标的偏差。

边界必须清楚：AI 结果只进入建议或候选草稿，不自动覆盖正文、Scene、地图或正史资产。

第一版不追求泛化 AI 写作平台，而是把写作页内最常见的“卡住一下”场景做顺：

- 无选中文本时，动作默认作用于当前光标附近段落和当前 Scene。
- 有选中文本时，动作只作用于选区，并在结果中标明来源选区。
- 输出以“可插入建议”呈现，用户点击后才写入正文。
- 所有 AI 调用继续走上下文确认记录，保留 action、scope、chapter_index 和 scene_id。
- 每个建议必须能取消、复制、插入到光标处或替换选区；第一版不做自动批量应用。

### C. 独立 Scene 整理工作台联动

把写作页里低频但复杂的整理能力外移，形成独立整理工作台。写作页只保留入口、当前任务进度和回跳能力。

整理工作台围绕 Scene 权威模型，而不是 ChapterCard：

- 深度导入后的 Scene 提取结果复核。
- 章节正文与 Scene 的映射对齐。
- 未归类章节、空 Scene、跨多章 Scene 的可视化处理。
- 断章、移动章节、合并 / 拆分 Scene。
- 从章节正文提取 Scene 字段，并展示 diff / 来源 / 置信度。

这是信息架构收益最大的方向：它可以把写作页从“编辑 + 整理 + 导入 + 复核”的混合页面中解放出来，让写作页继续保持 Scene 驱动的正文工作台。

## 当前倾向

第三阶段当前确认以 **B：AI 写作工具胶囊成型** 为主轴。

理由：

- 前两阶段已经把写作页稳定成 Scene 驱动的工作台，下一步可以增强作者写正文时的高频微操作。
- `AI 工具 · 待定` 已经在编辑器周边预留入口，做 B 可以顺着现有 UI，不需要先重构信息架构。
- 冲突检查和 AI 修复建议已经验证了“AI 结果只作为建议，不自动改正文 / 正史”的交互边界。
- C 涉及 Scene 整理、导入、断章和对齐，范围更像独立工作台。先不动 C，可以避免第三阶段同时改写写作页和结构管理入口。

C 保留为后续方向；A 可以作为驾驶舱体验补强，不应抢占第三阶段主线。

## 待讨论问题

1. B 的第一版工具数量控制在几个：只做 3 个高频动作，还是保留 5 个动作？
2. 结果插入方式：默认“插入到光标处”，还是默认“打开建议弹窗后手动选择插入 / 替换”？
3. 是否允许“替换选区”，还是第一版只允许插入 / 复制，降低误操作风险？
4. 每次 AI 动作是否都弹上下文确认窗口，还是同一章节 / Scene 内短时间复用一次确认？
5. 是否把 `AI 生成草稿` 并入胶囊，还是继续作为更重的章节级动作保留在菜单里？
