# 地图中级版本与诡秘演示验收

目标画像是长期创作的作者。交付可独立维护的位置示意图，并在同一地图中查看图片底图与地点配图。
首次成图、修改后的恢复和演示时的查找效率是产品假设；自动测试不能代替真实作者反馈。

## 批次与验收

1. **日常维护**：无生图任务的空间节点可以改标题、移动目录和排序；绑定世界地点的名称仍由
   世界对象拥有。加载时能看到最新来源失效提示，历史版本保持不可变。
2. **看懂并修改**：候选比较覆盖地点、关系和图片配置；可以对照保存版。地图提供就地查找、
   定位、专注浏览及地点配图，保留键盘操作、撤销、CAS 冲突、刷新恢复和窄屏保护。
3. **真实演示**：复用 `诡秘之主_第一部 小丑_前60章`，保留 60 章正文和旧示意版本，新增
   有出处的廷根位置示意和 gpt-image 辅助图片。演示布局和视觉补全不写成世界正史。
   完成浏览、定位、编辑保存、候选比较、图片采用/配图/校准及刷新恢复的浏览器验收。

当前验收数据库是 `ai_novel_acceptance_guimi`；它不是可清空的自动测试库。任何写入前保留
数据库备份；不重导入、不重建、不自动清理。应用与 worker 必须显式选择该库。
现有项目无模型连接；使用内置 gpt-image 生成演示资产后走既有上传采用流程，站内直连付费生成
另行标记验证范围，不把 mock 或上传成功称作站内生图实测。

## 工程边界

- 影响 World 地图服务、地图 Vue 页面和现有测试；API 继续使用 `/api/world/map-atlas`。
- 复用不可变 revision、来源校验、owner/novel_id 门禁与现有私有图片存储，不新增数据库表或依赖。
- 本轮不扩展 document schema、不建立历史世界状态、公开读者/RP 地图、真实比例或行程计算，
  无需新架构 ADR。来源校验仅更新响应提示，不修改历史或放宽采用时的 confirmation 校验。
- 独立后端批次使用 worktree；集成后由未参与实现的子代理 review，并在隔离 worktree 修复。

## 验证与交付证据

- 定向 World/Vue 行为测试，跨栈收尾运行 `make test-ci TEST_WORKERS=2`。
- 使用专用测试库运行地图浏览器回归；任何测试清理只作用于当次合成测试数据。
- 诡秘项目通过实际浏览器与持久化读回验收，保留图片来源、截图及面试演示步骤。
- 深浅主题、390px 窄屏、键盘定位、失效来源、版本冲突和双重保存失败继续受保护。
- 收尾完成 `make docs-check BASE_REF=origin/main`、`git diff --check` 与相关权威文档同步；
  本地实现、提交、远端/CI、部署和站内生图实测分别报告。
