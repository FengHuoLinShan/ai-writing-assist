🧠 AI 结构化生成流程 候选先行 · Schema 校验 · Review · 人工确认

1 用户/API → AsyncTask 提交生成任务 (world/plot/chapter/review/memory 等)
2 Worker → task_handler FOR UPDATE SKIP LOCKED 抢占任务 → 标记 running
3 Context → 各模块 Facade 编译结构化上下文 (project / world / character / geo / memory / timeline / outline / rag)
4 LLMClient → OpenAI API 发送 Prompt + Context，请求 response_format 结构化输出
5 LLMClient → Pydantic 校验 validate(response_format) · 自动 retry · 最多 3 次
6 存储 → Candidate 表 写入候选池 (entity_candidates / memory_update_proposals / chapter card drafts)
7 ReviewService → 7 个 Checker 结构复查: Schema / 重复 / 知识边界 / 提前揭示 / 地理 / 时间线 / 实体引用
8 用户 → Facade 人工审核候选 → 编辑/接受/拒绝
9 Facade → Canonical 表 确认后写入正史 (world_entities / memory_records / chapter_cards)

📥 小说导入流程 文件 → 解析 → 正文 → 结构化抽取

1 用户 → Imports API 上传文件 (txt/epub/html/mobi/azw3, ≤50MB)
2 API → Imports Facade 验证文件类型 · 大小 · 路径安全 (os.path.basename)
3 Service → Parser 解析文件 → list[{title, content}]
4 Facade → Writing Facade 跨模块写入 WritingDraft (每章一条记录)
5 Facade → ImportRecord 记录导入元信息 (文件名/类型/章节数/状态)
6 deep 模式 → 抽取管道 依次触发: world extraction → character extraction → plot structure generation
7 Writing 保存 → RAG Task 自动入队 rag_index_chapter 异步任务

📋 上下文编译流程 组合层 · 按需加载 · 预算控制

1 LLM Task → Context Facade compile(scope + chapter_index + reveal_mode + viewpoint)
2 Compiler → Project Facade 项目元信息
3 Compiler → World Facade 世界对象 (按 reveal_mode 过滤 hidden_truth)
4 Compiler → Character Facade 人物档案 + 知识边界
5 Compiler → Geo Facade 地理信息 (可选地缘可达性过滤 + 历史时期)
6 Compiler → Memory Facade 长期记忆 (按 chapter_index 过滤 ≤ 当前章)
7 Compiler → Timeline Facade 时间线事件
8 Compiler → Outline Facade 剧情线 / 篇章纲 / 章节卡 / 伏笔 / 揭示
9 Compiler → RAG Facade 相似度检索相关片段 (混合评分排序)
10 Compiler → LLM Task 返回 StructureContextBundle (含 budget_used / warnings)

🔍 结构复查流程 7 个检查维度 · pass/minor/major/reject

1 用户/Worker → Review Facade submit(target_type, target_id) → async task
2 ReviewService → Schema Checker 必要字段完整性校验
3 ReviewService → Duplicate Checker 候选 vs 正史查重 (精确名称 + 模糊 + 向量)
4 ReviewService → Early Reveal Checker 检查是否过早揭示秘密 (与 reveal_plans 对比)
5 ReviewService → Knowledge Checker 人物知识边界一致性 (角色是否知道不该知道的)
6 ReviewService → Geo Checker 地理一致性 (地点/通行/历史时期冲突)
7 ReviewService → Timeline Checker 时间线一致性 (事件顺序/因果链)
8 ReviewService → Entity Ref Checker 实体引用有效性 (引用的 ID 是否存在于正史)
9 Review Facade → 调用方 ReviewReport {decision, score, problems[], warnings[], revision_instructions[]}

🔀 完整数据流全景 创作流程端到端

① World Building → WorldEntity 创建世界对象、关系网络、地理层级、历史时期
② Character → CharacterKnowledge 创建人物档案、定义知识边界、角色关系
③ Plot Structure → Outline Layer 剧情线 → 篇章纲(三幕) → 章节卡 → 伏笔/揭示计划
④ Writing → WritingDraft 按章节卡撰写正文 → 自动触发 RAG 索引
⑤ Memory → MemoryRecord AI 从正文抽取状态变化 → 生成 memory proposals → 用户确认
⑥ Timeline → TimelineEvent 维护正史事件顺序 · 关联人物/实体/地点/剧情线
⑦ Review → ReviewReport 对候选/正史做 7 维度一致性检查
⑧ Context → Bundle 聚合所有模块数据 → 编译为 LLM 可读的结构化上下文
⑨ RAG → Retrieval 语义检索 (向量 + 关键词 + 关系 + 重要性 混合评分)
