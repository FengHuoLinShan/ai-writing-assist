AI 长篇小说结构化创作引擎 — 架构总览

事实层 · 结构层 · 辅助层 · 基础设施 · 12 业务模块 · 20+ 数据库表 · 7 个 Prompt

事实层 · 6 模块

  • • project: projects — 系统根聚合
  • • world: world_entities / relationships / entity_aliases / entity_candidates — 4 表
  • • character: characters / character_knowledge — 人物档案+知识边界
  • • geo: geo_locations / geo_edges / geo_eras — 地理层级+通行+历史
  • • memory: memory_records / memory_update_proposals — 8 种记忆类型
  • • timeline: timeline_events — 正史事件顺序

结构层 · 5 表

  • • PlotThread: 6 种剧情线 (main/secondary/hidden/villain 等)
  • • OutlineArc: 三幕结构 (entry_hook→midpoint→climax→result→next_hook)
  • • ChapterCard: chapter_goal + scene_cards JSONB 内联
  • • ForeshadowingPlan: planned→seeded→reinforced→paid_off 生命周期
  • • RevealPlan: reveal_stages JSONB 分步揭示

辅助层 + 基础设施

  • • rag: rag_chunks — pgvector + 混合评分检索
  • • review: review_reports — 7 个检查维度
  • • writing: writing_drafts — 版本管理 (novel+chapter+version)
  • • imports: import_records — 元数据不存正文
  • • infra: AsyncTask — FOR UPDATE SKIP LOCKED 轻量队列

分层职责

  • • API: 端点定义, 无逻辑
  • • Facade: 跨模块稳定入口, 组合调用
  • • Service: 核心业务编排
  • • Repository: SQLAlchemy 异步数据访问
  • • DB: PostgreSQL 17 + pgvector + pg_trgm

跨模块铁律

  • • ✓ 只能导入 contracts.py 和 facade.py
  • • ✗ 禁止导入 models / services / repositories
  • • ✗ API 层不写复杂业务逻辑
  • • ✗ facade 不写复杂业务逻辑
  • • ✗ 禁止拼接原始 SQL (参数绑定)

核心设计决策

  • • 少 Agent, 强 Context — 4 核心 + 3 工具型 Prompt
  • • 候选先行, 人工确认 — 不直接写入正史
  • • 实体抽取不是 NER — 只服务长期创作资产
  • • 场景卡不拆独立表 — chapter_cards JSONB
  • • PostgreSQL 任务队列 — FOR UPDATE SKIP LOCKED

AI 生成流程

  • • 提交 → Worker 抢占 (FOR UPDATE SKIP LOCKED)
  • • Context 从 8+ 模块编译上下文
  • • LLM 结构化输出 + Pydantic 校验
  • • 写入候选池 (entity_candidates / proposals)
  • • Review 7 维度检查 → 用户确认 → 正史

导入 & 复查

  • • 文件导入: 校验 → 解析 → WritingDraft
  • • deep 模式: 自动触发 entity/character/plot 抽取
  • • 保存时自动入队 RAG 索引任务
  • • 复查: Schema / Duplicate / Early Reveal
  • • 复查: Knowledge / Geo / Timeline / Entity Ref

全景管道

  • • ① World Building → ② Character → ③ Plot Structure
  • • ④ Writing → ⑤ Memory → ⑥ Review
  • • ⑦ RAG + Context Compile → 支撑下一轮 AI 生成
  • • 所有步骤支持 reveal_mode 信息过滤
  • • Context 支持 viewpoint_character_id 视角过滤
