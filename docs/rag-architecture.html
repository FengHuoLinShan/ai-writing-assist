RAG 混合检索系统

混合检索 (向量 45% + 关键词 30% + 关系 15% + 重要性 10%) · pgvector · Chinese-first

索引流程

  • • 草稿正文 → 场景感知分块 (28 种切换模式)
  • • 角色/实体/剧情线词项匹配到各文本块
  • • 批量生成 embedding (失败不阻塞)
  • • 删除旧块 → 批量创建 → 记录 embedding_status

检索流程

  • • 查询展开: 项目词典匹配 + n-grams 扩展
  • • 混合召回: Keyword ILIKE + Vector cosine
  • • 加权融合: 0.45v + 0.30k + 0.15r + 0.10i
  • • 语义去重后返回 + degraded 降级标记

跨模块集成

  • • World facade: 角色列表、实体词项、重要性映射
  • • Writing facade: 草稿正文、章节索引列表
  • • Context 模块: 按检索结果编译上下文包
  • • World character capability: 逐角色检索文本块抽取特征
