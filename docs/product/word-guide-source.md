# NovelCraft 新用户指南（Word 版）

**这是一份写给第一次使用 NovelCraft 的朋友的说明书。不需要懂电脑，只要会点鼠标、会打字，就能看懂。**

NovelCraft 是一个 AI 写作和互动故事网站。它帮你做两件事：

1. 如果你在写小说：它帮你记住人物、地点、剧情、正文版本，AI 可以给你提建议，但**不会替你乱改**。
2. 如果你想进入喜欢的作品世界：你可以用大白话告诉它“我在哪个世界、我是谁、从哪里开始”，它就能陪你互动式地往下走故事。

> 网址：<https://novel.zhh.se>
> 使用前需要注册账号，并在“账户设置”里连接你自己的 AI 服务钥匙（后文会解释）。

---

## 一、第一次使用：三步开始

### 第 1 步：注册账号

1. 打开网站 <https://novel.zhh.se>。
2. 按页面提示注册账号并登录。

### 第 2 步：连接 AI 服务（最重要的一步）

没有这一步，网站可以打开、可以看，但 AI 生成功能会用不了。

1. 登录后，看页面**右上角**，有一个**圆形头像按钮**（账户菜单），点它。
2. 在弹出的菜单里，点 **“账户与模型连接”**。
3. 在“连接 AI 服务”区域：
   - 选择一个服务（例如 DeepSeek）；
   - 在“服务密钥（API Key）”输入框里粘贴你从服务商那里拿到的 Key（可以理解成一把“钥匙”）；
   - 点 **“验证、保存并使用”**。
4. 看到提示“已启用”，就说明连好了。

> 什么是 API Key？它就是模型服务商发给你的“钥匙”。你要先去服务商网站注册、充值，拿到这把钥匙，粘贴到这里，NovelCraft 才能替你调用 AI。钥匙只会加密保存在你自己的账号下。

### 第 3 步：回到首页，选择你的入口

首页会问你“今天想怎样进入故事？”，只有两个大按钮：

| 按钮 | 适合你吗 |
| --- | --- |
| **我是作家** | 你在写小说、维护世界观、需要长期整理设定和正文 |
| **进入互动故事** | 你想直接进入某个作品世界，自己扮演角色、推动故事 |

点其中一个，正式开始。

## 二、先认清三个“总开关”位置（不迷路的关键）

很多功能找不到，是因为它们藏在三个固定位置。记住这三处，基本不会迷路。

### 1. 左侧一列按钮（进入作家项目后才会出现）

进入作家项目后，屏幕左边有一列导航按钮，从上到下是：

| 左侧按钮 | 它是干什么的 |
| --- | --- |
| **首页** | 也叫“今日工作”。显示“继续写作”“待处理”“正在整理”等入口 |
| **写作** | 写正文、分章节、看版本 |
| **人物与世界** | 人物、地点、关系、世界笔记 |
| **故事结构** | 大纲、篇章、剧情线、场景 |
| **地图** | AI 地图册 |
| **查找正文与资料** | 搜索小说正文里的内容 |

### 2. 左上角 / 首页的“切换作品”

想换一个作品写，就找 **“切换作品”** 按钮（在左侧顶部项目名称附近，或“今日工作”页的右上角）。

### 3. 右上角的“账户菜单”

右上角圆形头像按钮，点开后：

| 菜单项 | 干什么 |
| --- | --- |
| **账户与模型连接** | 连接 AI、换模型、连图片服务、写作偏好 |
| **账户信息** | 看身份与安全设置 |

### 4. 左侧“更多”按钮

左侧导航往下，有一个 **“更多”**。点开后还有三个入口：

| 更多里的入口 | 干什么 |
| --- | --- |
| **导入与整理** | 新建作品、导入已有小说文件、管理作品、回收站 |
| **高级工具** | 给进阶用户：世界设定共创、角色视角正文、上下文工具 |
| **项目偏好** | 当前作品的偏好设置 |

> 小口诀：**写正文去左侧“写作”，管设定去“人物与世界”，管结构去“故事结构”，导作品找“更多”。**

## 四、每个页面里到底有什么（怕乱就看这里）

### 1. 今日工作（左侧“首页”）

进入项目后默认到达的页面。它把你最该处理的事放在一起：

- **继续写作**：从上次停下的地方继续。
- **需要你决定**：AI 整理出来、等你审核的内容（不会自动生效）。
- **正在进行的整理**：导入等后台任务进度，离开页面也不会断。

不知道今天干什么，就打开这一页，点最上面的大按钮。

### 2. 写作页

- 左侧是**章节树**，点章节名切换正文。
- 中间是**正文编辑区**，直接打字。
- 上方有**版本下拉框**：可以看“正式正文 / 工作稿 / 待处理 / 历史”。
- AI 生成的内容会以“候选”形式出现，你点采用才会变成正文。

### 3. 人物与世界页

顶部有四个标签：

| 标签 | 内容 |
| --- | --- |
| 人物与设定 | 所有人物、地点、物品设定 |
| 关系 | 人物/事物之间的关系 |
| 世界笔记 | 世界书、规则、背景说明 |
| 需要决定 | AI 抽取出的候选，等你审核 |

### 4. 故事结构页

顶部四个标签：故事总览、篇章、剧情线、场景。写长篇小说梳理结构时来这里。

### 5. 地图页（AI 地图册）

从已确认的世界资料生成地图图片。新生成的地图先放在“本次生成结果”里，你点 **“加入地图册”** 才会正式使用；点 **“不加入”** 就不会影响你的地图册。

### 6. 查找正文与资料页

像搜索一样，输入关键词，从你的正文里找相关内容，并显示来源。

### 7. 导入与整理页（左侧“更多”里）

这是“作品档案”页，用来新建作品、导入小说、搜索项目、管理作品、回收站。

### 8. 账户与模型连接页（右上角账户菜单里）

三个区域：连接 AI 服务、OpenAI 图片服务、通用创作偏好。

## 五、给完全不懂电脑的人：几个重要提醒

1. **AI 不会背着你乱改东西。** AI 生成的内容先放在“候选”或“待处理”里，你明确点“采用/加入”，它才会成为正式内容。不点，它就一直只是建议。

2. **刷新或断网不会丢故事。** 写过的正文和故事内容会自动保存；故事生成到一半断了，已显示的内容会被保留，你可以选择保留或重来。

3. **费用是你自己的。** 网站不送模型额度。调用 AI 的费用由你的 API Key 对应的服务商收取。第一次保存 Key 时会做一次极小验证，可能产生几分钱费用。

4. **作家和互动故事是两套独立的数据。** 你在“人物与世界”里整理的设定，不会自动跑进互动故事；互动故事也不会写回你的小说设定。两边互不干扰。

5. **互动故事的分支规则。** 重新生成不会覆盖原来那段，而是开一条新分支。只有你当前选中的分支会进入后续故事。没选中的不会影响你。

6. **这是测试版本（Alpha）。** 功能还会继续改进，界面也可能调整。遇到按钮位置和本指南写的不完全一样时，先按“左侧导航、右上角账户、更多”三个位置找。

## 六、常见问题

**问：我没有 API Key，能用吗？**
答：可以注册、浏览界面，但不能使用 AI 生成、导入整理等功能。先去模型服务商那里申请一把 Key。

**问：AI 会乱改我的正文吗？**
答：不会。AI 的建议要先经过你确认。它不能直接覆盖正式正文。

**问：为什么我点了“写作”，却提示先选作品？**
答：因为你还没进项目。先去“导入与整理”或首页选择/新建一个作品，再点左侧功能按钮。

**问：为什么地图册不能生成？**
答：通常有三个原因：没有连接图片服务、没有已确认的世界资料、或没有可用的地图层级。先到“账户与模型连接”里连接图片服务，再到“人物与世界”确认一些地点设定，然后重试。

**问：我找不到某个功能了。**
答：按这个顺序找：先看左侧六个按钮；再看左侧“更多”；最后看右上角账户菜单。九成功能都在这些地方。

## 七、术语大白话对照表

| 界面上的词 | 它是什么意思 |

| 回顾 | AI 自动整理的故事记忆摘要 |
