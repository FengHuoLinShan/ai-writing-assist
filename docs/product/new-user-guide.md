# NovelCraft 新用户指南

> 一句话：NovelCraft 是一个 **AI 长篇创作与私人故事引擎**。
> 作家用它管理数十万字正文与长期设定；RP 用户用它进入喜欢的幻想世界，进行一段由自己选择推动的私人故事。
> 线上入口：<https://novel.zhh.se>（需注册；模型调用需在账户设置中连接自己的 API Key）

---

## 1. 这是什么

NovelCraft 有两个入口，对应两类完全不同的用户：

| | 我是作家 | 我是 RP 用户 |
| --- | --- | --- |
| 适合谁 | 正在写长篇小说、认真维护幻想世界的创作者 | 想进入优秀作品世界、自己推动一段故事的人 |
| 你得到什么 | 正文版本、Scene、世界设定、大纲、检索证据和 AI 建议在同一条可追踪工作流里 | 用自然语言说明世界、身份和开场，就能持续互动、重新生成、切换分支 |
| 需要准备什么 | 一部作品（新建或导入）＋ 自己的模型 API Key | 一个想进入的世界＋ 自己的模型 API Key |
| 核心承诺 | AI 输出先成为候选，你采用后才成为正式内容 | 只有你选中的故事分支才会进入后续剧情 |

两条路径共享账号和模型连接，但**不共享复杂首屏**：首页只有两个大框，作家获得完整控制，RP 用户获得低门槛开场。

---

## 2. 作家路径：从导入到安心续写

1. **创建项目或导入作品**：支持新建空白项目，也支持导入已有文本。深度导入会分阶段解析章节、Scene、世界对象和剧情结构，结果先进入待审核区。
2. **写作工作台**：正文按版本保存；AI 生成的内容以“候选”形式出现，你编辑、采用后才会成为正式正文。
3. **世界设定**：人物、地点、关系、时间线等长期事实集中管理；AI 抽取的世界对象先进入“待处理”，审核通过后才进入正式设定。
4. **大纲与剧情线**：总纲、剧情线、篇章纲与 Scene 分层组织，把创作意图变成可执行结构。
5. **小说检索**：AI 检索返回带来源证据的正文片段，而不是一段不可解释的答案；检索结果是否允许进入本轮生成，由系统上下文规则决定。
6. **AI 地图册**：基于已确认资料生成候选图片，图片同样遵循“先候选、后采用”的边界。

---

## 3. RP 路径：进入一段属于你的私人故事

1. **创建旅程**：可直接说明世界、身份、时间地点和开场愿望；也可选择已有作品或导入 txt/epub/html/htm。
2. **作品资料（可选）**：作品不必完结。当前版本的全部现有章节完成整理、索引和必要歧义确认后，选择章节内剧情点与原作/原创玩家身份；自然语言描述只列出候选，仍由你点选确认。整理中可以离开后恢复。
3. **持续互动**：用自然语言行动、暂停、纠正；每段回复以不可变节点保存，重新生成不会覆盖旧内容。
4. **重新生成与分支**：对某段不满意时重新生成，会创建同级分支；你可以切换分支，只有当前选中的路径会进入后续故事。
5. **自动回顾**：系统只基于选中历史生成概要，并在 7 个自然语言分区中维持总回顾，长故事不断片。
6. **看海循环**：可选的自动连续阅读模式，由前台驱动、有明确停止边界；你离开故事页，循环就会停止。
7. **断流恢复**：流式内容按节拍持久化，刷新、停止或网络波动后，已看到的内容不会丢。

---

## 4. 第一次使用：快速上手

1. 打开 <https://novel.zhh.se> 并注册账号。
2. 进入 **账户设置**，连接自己的模型 API Key（文本连接和图片连接相互独立；文本生成和图片生成分别使用对应连接）。
3. 回到首页，选择入口：
   - **我是作家**：创建项目 → 导入或直接写作 → 等待导入/生成任务完成 → 审核待处理资产 → 继续创作。
   - **我是 RP 用户**：创建旅程 → 直接开场，或选择/导入作品资料后确认剧情点 → 开始互动。
4. 任务在后台进行时，你可以离开页面；系统会保存进度，回来后按状态恢复。

---

## 5. 费用与密钥

- 项目**不提供公共共享账号**，也不包含真实稿件、密钥或个人联系方式。
- 模型调用使用**你自己的 API Key**，费用由对应模型供应商按用量收取。
- API Key 先经过最小真实调用验证，再加密保存；项目内只保存非敏感的工作流偏好。
- 线上入口可用性以 `/api/health` 为准；线上版本可能落后于仓库最新代码，以 release 记录为准。

---

## 6. 你需要知道的当前边界

NovelCraft 当前是 **Alpha / 工程验证系统**，不是成熟商业产品：

- 尚未通过正式用户研究证明留存、付费意愿和真实创作效率提升。
- RP 不提供多作品 crossover、项目共享和公开发布。不使用作品资料时仍依赖模型训练知识；使用作品资料时也只能引用所选版本和剧情截止点前的内容。
- “模型知道”或“用户已导入”都不等于用户天然拥有传播、改编或商业使用权。
- 多人实时协作和大规模容量验证不在现阶段完成范围内。

## 7. 常见问题

**我没有 API Key，还能用吗？**
可以注册和浏览界面，但生成、导入、检索等 AI 能力需要先连接自己的 API Key。

**AI 会乱改我的正文或设定吗？**
不会直接改。AI 输出先进入候选或待处理区，只有你明确采用（或经过授权的可回滚流水线）才会写入正式资产；未采用的建议会保留证据与历史。

**刷新页面会丢内容吗？**
关键内容（正文、故事节点、已看到的流式正文、任务进度）都有持久化和恢复机制。RP 故事刷新后可从断点继续。

**作家项目里的设定会自动进入我的 RP 旅程吗？**
不会。只有你在新旅程中明确选择“使用作品资料”、确认资料版本和剧情进度后，系统才会为该旅程只读引用。RP 故事和原创身份始终不写回作者项目。

**重新生成会覆盖原来那段吗？**
不会。原内容保留为兄弟节点，重新生成创建新分支；未选中的分支不会进入后续 Prompt、导出或回顾。

**支持哪些模型？**
账户文本连接当前以 DeepSeek 为已验证默认；Kimi 与长上下文能力需通过显式真实门禁后才会启用。图片连接使用独立的图片模型连接。具体以账户设置页和最新 release 记录为准。
