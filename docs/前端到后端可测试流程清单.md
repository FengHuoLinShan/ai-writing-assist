# 前端→后端可测试流程清单

## 测试层级说明

| 标记 | 含义 |
|------|------|
| 🔵 单步 | 一个用户操作 → 一次 API 调用 → 一个响应 |
| 🟢 多步 | 一个操作 trigger 多个 API 调用 |
| 🟡 异步 | 涉及异步任务，需要轮询 `api/tasks` |
| 🔴 复合 | 先编译上下文 → 再调用 LLM → 再入库 |

## TDD 建议测试顺序

### 第一轮：纯 CRUD（无外部依赖）

project → world(2.1~2.9) → character(4.1~4.9) → geo(3.1~3.10) → memory → timeline → outline(7.1~7.15) → writing(11.1~11.6)

### 第二轮：依赖第一轮 + LLM mock

rag → context → review(10.1~10.3)

### 第三轮：异步任务 + 端到端

world(2.10) → character(4.10~4.12) → outline(7.11/7.16) → imports → generate
