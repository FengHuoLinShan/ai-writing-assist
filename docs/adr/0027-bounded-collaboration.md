# ADR-0027 — 有限协作与角色排演

- 状态：Accepted / Implemented (experimental, quality gate closed)
- 日期：2026-09-20
- 授权：用户要求参考完整 Agent Teams 计划实现并完成，允许 deepseek-flash；不使用开发子代理。

## 决策

在 ADR-0023 的既有 Project gateway、PydanticAI、PostgreSQL 任务、Evidence 和领域回执上，
允许服务端注册业务蓝图的有限协作。此许可覆盖深度审稿、世界压力测试、跨章修订、Scene
排演、RP 多角色、盲读、专题研究和导入疑难会诊；是否可启动由各功能当前实现与独立能力
开关决定，不意味着全部已实现、质量通过或允许生产启用。

一个宿主持有一个有效任务租约；进程内最多并发三名成员。成员使用独立短事务 session、
独立模型历史和受限 Evidence 投影，共享现有 root run 和预算，不获得独立的完整额度。
旧 AgentRunBudget 默认 legacy_v1；team_v1 为总请求 30、工具尝试 48、联网 4，仍受原
1800 秒截止与 AIRunEnvelope 约束。调查成员额度和终检保留额来自冻结蓝图，不重复计费。

首版沿用 AssistantRun.checkpoint_json.collaboration_v1，单一协调写入，最大 1 MiB。
成功成员有输入/输出 hash 和持久化回执；恢复复用成功项，未结算消费保持未知。普通成员
失败只阻塞其依赖：坏响应、内容过滤、超时及连接错误按成员记录；账户限流、配额、认证、
租约、权限、项目或来源失效停止整组。版本不兼容明确拒绝，不升级旧运行。

交接携带全部来源依赖；摘要继承限制。接收者不能接收其授权范围之外的成果；无法确定时拒绝，
不让模型自称“已去敏”。作者调查与角色模拟分开：角色只观察已裁决且对其可见的事件，
同回合意图不互相可见，盲读历史不接收未来故事或答案。

Assistant 保存讨论、任务与候选成果；World/Writing/Story/Interaction 保持领域事实与采用权。
调查结论送回原领域复核，只有领域受理结果可显示为已核实问题。写入仍须原领域具体确认、
来源重验和事务；不新增正史库、任意代码执行、通用自治 API 或跨进程成员队列。

## 交付与验证

工程、真实模型质量和生产启用分别记录。确定性检查须覆盖隔离、预算竞争、失败、取消、
恢复、幂等和来源漂移；PostgreSQL 验证真实事务/租约，浏览器验证原位入口及离开恢复。
模型比较只用授权的合成脱敏资料，保留实际用量与失败；未完成人工盲评或无稳定收益时保持
实验入口，不宣称优于原方案。每次团队选择仅授权一条提交，成功或恢复到回执后清空，后续发言须重新选择团队。
普通关闭阻止新运行及新方案物化、保留旧回执；已物化批次仍走作者确认，但关闭后不启动修改后复核，
明确返回未检查。紧急停止沿原取消传播。
历史表拒绝 UPDATE 与直接 DELETE，沿用父对象永久删除的级联例外。日常回退只关闭入口并保留历史；
两条迁移仍提供对称 downgrade（删除新增表/列/约束/函数），仅在已授权可丢弃数据或完成备份的环境运行。

实施进度和验收证据见 `.agent/tasks/2026/T-20260920-agent-teams/TASK.md`。
