# ADR-0019 — 现代简约视觉系统与浏览器本地主题资源包

- 状态：Accepted
- 日期：2026-09-07
- 授权：用户确认全站体验重构、中性精致默认风格、完整视觉资源包、本浏览器存储、替换旧主题及手机完整工作流，并要求执行。

## 决策

保留 Vue 3 island、hash router、bridge、业务 API 和领域会话；主题归前端外观，不进入账户连接、作品偏好或 `novel_id` 业务数据。设备外观跨本浏览器账号保留，不包含账户或作品内容。

默认主题为现代简约；`nc-theme` 保存 `light / dark / system`，`data-theme` 只表示解析后的 `light / dark`。旧 `sticky / ink / paper / warm / minimal` 迁移到浅色，`night / dark-soft` 迁移到深色。系统模式监听系统明暗变化；手动模式不随系统改变。

新增 `ThemePackageV1` 本地 ZIP 接口：`theme.json`、声明的 `assets/` 和可选 `LICENSE.txt`。语义变量、字体及固定装饰区域可定制，不能导入 CSS、JavaScript、HTML、SVG 或远程地址。精确规范见 [主题包规范](../frontend/uiux/theme-packages.md)。

浏览器原生 IndexedDB 数据库 `nc-theme-packages` 保存完整包及经校验资源。应用偏好和经校验的启动色值缓存放在 localStorage。导入为显式文件选择、受限解压、校验、隔离预览、保存并应用；取消不改变现用主题，替换和删除有确认。刷新时资源缺失或损坏恢复内置外观并说明原因，持久化失败不得声称已保存。

ZIP 使用按需加载的 `fflate`；解压运行在同源模块 Worker，限制输入、实际展开字节、数量和时间。Worker 纳入生产 manifest/inventory；CSP 不增加 `eval`、外部域名或 blob worker 权限。图片通过本地 Blob URL，字体通过 `FontFace` 二进制源使用；切换和取消释放资源。

## 影响与替代

这次明确取代旧 UI/UX 修复批次的“三主题、只改样式、不新增依赖”范围约定；保留该批次的安全、恢复和可访问性要求。只增加解压依赖，不采用 UI 框架、Vue Router、状态库或服务端主题存储。

手机与桌面共用编辑器和保存控制器。章节与本章资料在手机使用模态抽屉；断点和主题变化不替换正文节点。已采用资料、AI 待处理边界、账号与作品隔离均保持。

## 验证

单元检查验证迁移、系统监听与资源配置边界；真实浏览器覆盖字体、图片、预览取消、导入持久化、刷新、导出、删除、非法与超限压缩包以及手机正文节点稳定性。构建必须验证 Worker 和所有主题示例资产都在发布清单内。全站功能和视觉回归使用独立测试库。
