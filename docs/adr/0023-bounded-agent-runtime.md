# ADR-0023 — 有界 Agent 核心与项目助手

- 状态：Accepted / Implementation in progress
- 日期：2026-09-10
- 授权：用户明确要求完整实施“NovelCraft Agent 核心接入与全项目能力整合计划”。

## 决策

在现有 LLM gateway 和 PostgreSQL task runtime 上接入 PydanticAI 有界单 Agent 循环，
用于项目助手和 RP 每轮故事。允许模型在服务端注册、授权、预算和可见性约束内自主选择
读取与提案工具；业务修改由具体成果批次确认后交给领域执行。此决定取代全局禁止模型
选择工具的旧限制，不授权自治多 Agent、任意代码/SQL/文件访问或绕过业务门禁。

Assistant 拥有通用讨论、运行、操作提案及提醒展示状态；World 继续拥有事实、候选和复核，
Story/Writing/Interaction 继续拥有本域资产。World 通用共创会话迁移时保留身份及成果引用，
不能双写；RP 消息树、选中路径、回顾及 attempt 不迁为普通聊天记录。

模型客户端必须通过 Project facade 解析当前已验证账户连接或冻结的无 secret 快照。
PydanticAI 通过项目模型适配器复用 gateway、限流、错误分类和取消；不得新建私有凭据路径。
现有确定性导入/索引/生成工作流继续使用其稳定接口。新协议加性支持工具、引用和供应商
续接，不让 raw/extra 代替结构化信任边界。

内部工具继续通过 Evidence 按来源版本、排除项和作者/读者/角色可见性物化资料。外部查证
按用户于 2026-09-10 批准的补全计划改用自托管 SearXNG 与受控网页读取，只传必要问题；原作 RP 仅通用事实联网，外部材料不能
补全原作未来、扩张角色知识或授权工具。网页资料、模型推断和聊天讨论都不自动成为正史。

运行有请求/工具尝试/联网次数、上下文及总时限上限，恢复不重置累计预算。任务、lease、
CAS、操作回执、取消与错误恢复仍由代码拥有；provider 等待期间不持有数据库事务。
工具写入执行前重验授权与来源；批次按业务原子组执行，失败阻断依赖，重试不得重复执行。

主动服务需持久化项目级持续授权，按变化合并运行，默认关闭。提醒仅是领域结果的展示投影，
忽略提醒不解决领域问题；来源变化使旧建议失效。既有授权流水线和 RP 发送/继续/看海所覆盖
的领域输出语义继续有效。

World 已发布的复核政策继续优先，包括作者明确关闭语义复核的选择。没有已发布政策时，
助手的复核/主动服务授权可运行 World 持有的固定建议性语义检查：问题与政策快照保存在
该 WorldValidationRun 的计划内，不创建或发布全局政策页面，不改变 Canon 准入规则。
此类回执标为 `assistant_advisory`，不得充当正式采用许可；后来发布政策会使旧诊断失效。
每个后续分片重新检查来源与政策，不继续用已失效资料生成建议。

人工正文可在本次助手请求或项目持续授权内运行 Writing 持有的世界约束审查。Evidence
只回传经过范围、排除与可见性检查的实际来源；结果保存来源指纹、覆盖和遗漏，世界来源
变化后回访提示需重新检查。此模式不签署人物知识边界，不改变 AI candidate 原生成
confirmation 的独立审查与采用门禁。

## 影响与验证

修改共享 LLM 协议、任务执行与跨域工具入口时须同时验证旧文本调用、工具协议、权限/来源、
供应商差异、预算、取消/重启/重放及并发。新增 Assistant 数据、会话迁移、作者/RP 前端与
主动服务按各阶段独立门禁交付；仅 SDK 接通不构成此 ADR 的完整实现。

实施状态与证据保存在任务记录和阶段交付中；模型能力只有真实兼容门禁通过后才可对外声明。

## 自建查证与剩余功能补全

作者新运行协议 v3 冻结工具目录及 `searxng-v1` 搜索配置指纹；RP 新执行快照 v2 另外冻结旅程
明确开启的搜索选择。旧原生联网授权不自动迁移到新渠道，旧运行保留原协议。业务模型与 Key
继续经 Project 解析；搜索服务没有独立模型、任务队列或作品事实库。

只注册搜索和本轮结果引用读取工具，公网检查覆盖重定向与实际连接。搜索、读取和模型用量
分别记录；可选联网额度耗尽不能无故终止不依赖联网的故事。当前网页与故事来源仍遵守独立
的可见性、原作信息保护和引用验证，不以搜索结果补全原作或授予角色知识。

领域维护继续使用原采用/发布/恢复接口。结构变更同时保存旧关联场景，用于与新范围合并
检查；新剧本的 `basis_manifest.version=2` 跟踪明确关联的剧情线、篇章、伏笔和揭示，旧剧本
按原 v1 算法核对，不能因算法升级自动判为过期。计划检查只是版本提醒，不冒充语义结论。

本轮功能补全与 Computer Use 开发模拟继续进行。用户已将人工质量、效率指标、正式验收和
生产发布移出本轮；必要工程检查继续，不能将开发模拟描述为完整产品验收。
