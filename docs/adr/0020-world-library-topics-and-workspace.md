# ADR-0020 — 资料库主题目录与作者工作区

- 状态：Accepted
- 日期：2026-09-09
- 授权：用户确认“世界观能力对齐与作者工作台优化”第一期方向：主题目录＋类型筛选、同一资料多主题引用、服务端统一资料列表、作者工作区（收藏/最近访问/视图偏好），沿用现有建议与 Canon 生命周期。

## 决策

World 模块新增自有数据 `world_library_topics` / `world_library_topic_members` / `world_library_favorites` / `world_library_recents` / `world_library_workspace_profiles`，全部保持 owner 与 `novel_id` 隔离，随项目 CASCADE 删除。

主题目录是纯作者组织工具：`parent_id` 用 `(novel_id, parent_id) → world_library_topics(novel_id, id)` 复合外键保证同项目嵌套，service 层在移动时拒绝成环；归档主题不归档成员与子主题。成员以 `target_kind + target_id` 引用现有 Page / Draft / Entity（多主题引用，无跨表外键），独立工作稿发布时由 lifecycle 把 draft 引用转换为 page 引用并去重，收藏与最近访问同步转换。目录关系不构成地理或事实依赖，不进入生成上下文，也不改变 Canon。

统一查询 `GET /api/world/library` 以 SQL UNION 合并 Page（left join 其唯一活跃工作稿，同一正式页和工作稿只显示一项）、独立工作稿与已采用对象，支持搜索、类型、形态、状态、主题（含子树）、收藏、未归类、排序与 `skip/limit` 完整分页（默认 50）。归档对象默认隐藏，可按状态显式检索；未归类资料始终可通过“未归类”过滤找到。主题与工作区分别提供窄 CRUD 接口，不新增 Card 内容表，也不复制既有列表接口的写入能力。

前端资料库首页改为最近使用、收藏、继续编辑、主题目录与类型筛选入口；类型大卡缩为筛选 chips。结果视图由服务端统一列表驱动，筛选、排序、分页与主题全部写 URL，返回时按项目与查询恢复位置；服务端列表失败时回退到原客户端合并卡片并提示重试。桌面结果页为粘性目录导航，760px 以下目录改为抽屉。紧凑列表为默认布局，卡片视图保留。

## 影响与替代

考虑过把主题放进既有 `world_bible_categories`：类别是页面模板/分类的扁平正式概念，无法承载嵌套、多类型引用与工作区语义，扩展会污染其唯一键与模板耦合。也考虑过用 JSON 在页面上存目录归属：无法跨 Entity/Draft 使用、无法服务端分页统计，且删除目标时无法清理。多态引用不设跨表外键与 `asset_knowledge_tags` 的既有模式一致，由读取时 join 活跃目标与发布转换保证不悬挂。

该决定不引入新事实源：目录整理不改变 Canon，页面编辑不同步对象字段，收藏/最近访问只是作者视图状态。会话持久化（第三期共创）与复核所有权（第四期）另行决策，当前工作区不保存 checkpoint。

## 验证

后端 API 测试覆盖分页无重复遗漏、页与工作稿合并去重、搜索/类型/形态/状态/主题/收藏/未归类过滤、排序、主题嵌套/改名/排序/归档/防环/多主题引用/幂等成员操作、工作区收藏与最近访问、发布时 draft→page 引用转换（成员/收藏/最近访问）、跨项目隔离与视图偏好。前端 Vitest 覆盖首页分区渲染、URL 筛选恢复、服务端列表与分页器、目录切换语义、收藏与加入主题调用、手机抽屉与 44px 触控契约；全量套件与构建作为回归门禁。
