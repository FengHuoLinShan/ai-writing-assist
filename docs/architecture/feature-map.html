如何读这张图

  • • 每个功能域 → 具体能力 → 入口；入口 = 前端页面路由 + 注册表 canonical API 前缀及其下的真实子路径
  • • 这张图只回答「作者能做什么、从哪里进」；模块分层、依赖方向与运行时拓扑见配套的模块架构图（module-architecture）
  • • 普通 AI 输出先预览并由作者确认采用；明确授权的自动流水线可写允许的派生或已采用资产，保留来源与撤销回执
  • • 草稿、创作位置与长任务按保存回执恢复；未知付费结果先核对。作品删除进回收站，已采用资产按领域规则保留历史、撤销或废弃
