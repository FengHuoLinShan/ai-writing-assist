恢复与覆盖的限制

同一输入与完整请求证明一致才复用。未知用量不能记成零；恢复时先核对回执与费用。各流程的重试层级和上限不同，不能承诺没有重复费用。正文候选同键采用重放返回原结果。

地图册已保存版本的正文来源已有建议性核对（G8a）；非正文/待审来源与正典 revision 尚未接入统一自动失效消费者。图片实体在私有双 bucket 的同一单盘，另有同机独立目录的数据库配对副本（ADR-0034），整盘故障仍会丢失，不能替代异地备份。

正常文本 snapshot 拒绝旧本机文字配置；批准与设备领取入口只接受图片任务，旧文字 pending 记录置为 failed，源码兼容分支不是可领取入口。图片目录不是 OS 沙箱。

RP 使用自己的 attempt/context，不机械套用作者确认流程。本图是产品代码阅读示意，文档子代理组队不属于产品运行架构。
