完整架构图可在图内左右滚动；键盘可按 Tab 聚焦图，再用方向键移动。

模块数量

  • • 12 个活动业务模块（indexing/compilation 归 evidence，outline_state/continuity 归 story；evolution 已有 Scene 运行与项目所有权门禁）
  • • local_agent：本机图片工具；task + invocation 双租约出站领取，文字 snapshot 拒绝，批准/领取入口将旧文字 job 置 failed；图片/设备/历史回执保留；工作目录不是沙箱
  • • interaction 只读同 owner author source revision；私人旅程不写回原作
  • • frontend-console（client）与 backend/prompts（runtime-contract）纳入运行时共享带，图上均有节点
  • • Canonical API 使用 /api/evidence/* 与 account/project owner 路径；旧 /api/rag、/api/context、/api/settings 已退场

架构原则

  • • 运行时拓扑：浏览器 island → FastAPI；API / worker 经 bootstrap 装配 DI 与任务；API 入队 PostgreSQL async_tasks，run_worker.py 常驻领取
  • • 出站统一经服务端：LLM 走项目 owner 已验证账户连接；对象走私有 MinIO/S3 双 bucket（world 图片 + AI 地图册）；本机 CLI 走出站租约
  • • 跨模块仅通过 contracts.py、facade.py 或已注册 DI port；API 与 facade 保持薄层
  • • 模块内部由 API、领域服务、repository 与模型各自承担职责
  • • 组合根、迁移与测试 fixture 是受限模型导入例外

边界与读图

  • • 公开请求同时受 account owner、project novel_id 与 author / interaction kind 门禁
  • • 跨项目默认例外是同 owner、显式版本化的 author source → interaction 只读资料流；ADR-0024 仅允许配置固定且复验的 public source 进入匿名 RP
  • • AI 地图册是 world 子系统；图片候选不会自动成为世界事实
  • • 对象稳定设定与修订归 World，按 Scene 的状态归 Story，演化理解归 Evolution；统一读取由 Evidence 聚合
  • • 箭头表示主要调用或资料流，不是生产代码 import 图
  • • 引导流程复用 AssistantRun、领域任务与队列；任务自动批准需有限范围授权、指定模型校准及执行前重验，领域写入与回执仍归原模块
  • • Evolution 的类别补扫与选择性重做已有离线工程验证；真实模型、长篇质量与费用尚未验收
  • • 当前分层与可编辑图源以 module-architecture.drawio 为准
