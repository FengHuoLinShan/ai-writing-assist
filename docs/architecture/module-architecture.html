浏览器兼容预览 · 9 个业务模块 · 当前可编辑图源：module-architecture.drawio

模块数量

  • • 10 个活动业务模块（RAG + Context 已物理归入 evidence，含 story Scene 派生层）
  • • evidence 内部分 indexing / compilation；account/project 分拆配置所有权；interaction 不读取作者资产
  • • Canonical API 使用 /api/evidence/* 与 account/project owner 路径；旧前缀仅薄别名
  • • 已移除：geo / review / character / timeline（人物和事件能力并入 world）

架构原则

  • • 模块内部由 API、领域服务、repository 与模型各自承担职责
  • • 跨模块仅通过 contracts.py、facade.py 或已注册 DI port
  • • 组合根、迁移与测试 fixture 是受限模型导入例外
  • • 异步任务通过 enqueuer → worker 解耦（PostgreSQL 队列）

边界与读图

  • • 公开请求同时受 account owner、project novel_id 与 author / interaction kind 门禁
  • • AI 地图册是 world 子系统；图片候选不会自动成为世界事实
  • • 箭头表示主要调用或资料流，不是生产代码 import 图
  • • 当前分层与可编辑图源以 module-architecture.drawio 为准
