# AI 长篇小说结构化创作引擎：数据库设计 v2.0（实际实现）

## 1. 数据库设计原则

- **候选与正史分离**：AI 生成内容先进入 candidate / proposal。
- **状态优先于删除**：status 字段枚举（draft / candidate / canonical / deprecated / ignored / conflicted / pending / processing / done / failed）。
- **Prompt 合并，数据拆分**：生成阶段可以合并，入库按对象类型存储。
- **JSONB 存弹性字段**：场景卡放 chapter_cards.scene_cards JSONB。

## 2. 技术选型

- PostgreSQL 17（Docker 部署）
- pgvector：向量检索、对象去重、RAG embedding
- pg_trgm：名称相似、别名相似、重复对象检测
- JSONB + GIN：灵活字段和数组查询
- SQLAlchemy async（生产） / SQLite 内存引擎（测试）
- Pydantic v2 schema 校验

## 3. 完整表清单（活跃业务表 + 系统表。geo / review / timeline 模块已移除）

### 3.1 projects（小说项目）

```sql
CREATE TABLE projects (
    id UUID PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    genre VARCHAR(64),
    tone VARCHAR(64),
    language VARCHAR(16) DEFAULT 'zh' NOT NULL,
    target_length VARCHAR(32),
    current_stage VARCHAR(32),
    default_reveal_policy VARCHAR(32) DEFAULT 'author_safe' NOT NULL,
    created_at TIMESTAMP DEFAULT now(),
    updated_at TIMESTAMP DEFAULT now()
);
```

### 3.2 core_entities（共享核心实体表 — 取代 world_entities + entity_aliases）

```sql
CREATE TABLE core_entities (
    id UUID PRIMARY KEY,
    novel_id UUID NOT NULL REFERENCES projects(id),
    entity_type VARCHAR(32) NOT NULL,     -- character/location/faction/item/concept/event/creature/skill/rule/other
    name VARCHAR(255) NOT NULL,
    aliases JSONB DEFAULT '[]' NOT NULL,   -- 别名列表 [{alias, type}]
    summary TEXT,
    public_info TEXT,                      -- 公众已知信息
    hidden_truth TEXT,                     -- 仅作者视角
    content_json JSONB DEFAULT '{}',
    importance FLOAT DEFAULT 0.5 NOT NULL,
    importance_level VARCHAR(16) DEFAULT 'normal' NOT NULL,  -- core/important/normal/temporary
    reveal_level VARCHAR(16) DEFAULT 'author_only' NOT NULL, -- author_only/hinted/revealed/fully_known
    status VARCHAR(16) DEFAULT 'draft' NOT NULL,
    embedding_text TEXT,
    embedding vector(1024),
    search_text TEXT GENERATED ALWAYS AS (  -- 虚拟生成列：name + JSONB aliases 聚合，pg_trgm GIN 索引
        name || ' ' || COALESCE(content_json->>'aliases', '')
    ) STORED,
    created_by VARCHAR(64),
    approved_by VARCHAR(64),
    created_at TIMESTAMP DEFAULT now(),
    updated_at TIMESTAMP DEFAULT now()
);
```

## 4. 与原始设计的主要差异

| 项目 | 原始设计 | 实际实现 |
|------|---------|---------|
| import_records | 无此表 | 新增，用于小说文件导入跟踪 |
| character_knowledge | 使用 UUID 存储 target_id | 使用 String(36) 存储 UUID hex |
| relationships | source_id 使用 UUID 类型 | 使用 String(36) 通用引用 |
| core_entities (v2.0) | world_entities 表 + entity_aliases 表 | 合并为 core_entities 表，aliases 用 JSONB 内联 |
| characters (v2.0) | 独立 id PK + name/aliases/status/world_entity_id | entity_id PK+FK → core_entities.id，仅存人物特有字段；由 world 模块管理 |
| geo / review / timeline 模块 | 独立表和模块 | 已移除。geo 表/ review_reports / timeline_events 不再使用 |
| entity_aliases | 独立表，FK → world_entities.id | 已移除，别名存 core_entities.aliases JSONB |
| 测试引擎 | 仅提及 | 完整实现：SQLite 内存替代 pgvector（Text 存 JSON 序列化向量）|
