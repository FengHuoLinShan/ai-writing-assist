AI Writing Assist — 系统瘦身架构

以 world 模块 + RAG 系统为核心的最小可运行单元

必须保留 (6 个模块)

  • • world — 核心实体、关系、候选池、事件、人物
  • • rag — 分块、索引、混合检索
  • • context — 上下文编译（无独立表，编排层）
  • • project — 项目元信息，所有模块依赖 novel_id
  • • infrastructure/llm — LLM 客户端 + 7 个 Prompt
  • • infrastructure/tasks — PG 任务队列 + Worker

按需保留 (2 个模块)

  • • writing — 正文草稿管理，触发 RAG 自动索引
  • • imports — 文件导入管线，批量导入触发索引
  • → 如果不需要从正文抽取实体，二者都可去掉
  • → 纯手动创建实体则不需要 RAG 抽取链路

可独立删除 (4+2 个模块)

  • • geo — 地理关系，world 有兼容 stub 可移除
  • • outline — 剧情结构，与实体管理无关
  • • review — 结构复查，质量工具非核心
  • • memory — 长期记忆，独立功能
  • • character — 已并入 world，原模块可删除
  • • timeline — 已并入 world (entity_type="event")

AI Writing Assist · 系统瘦身分析 · 核心: world + RAG + context + infra
