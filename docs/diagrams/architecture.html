AI 写作助手 · 架构总览

分层模块架构 · FastAPI + PostgreSQL(pgvector) · Vanilla JS SPA · OpenAI 兼容 LLM

数据流模式

  • • 前端 → API (HTTP REST, JSON)
  • • API → Facade → Service → Repository → Model
  • • 深度导入: 文件 → 解析 → 分块 → LLM 抽取 → 实体自动写入
  • • 异步任务: POST → 任务记录 → Worker 轮询 (SKIP LOCKED)

模块约束

  • • 跨模块仅通过 contracts.py + facade.py 访问
  • • 不直接 import models.py / repositories.py / services.py
  • • API 层与 facade 层不写复杂业务逻辑
  • • 实体抽取不是 NER，不抽取路人/道具/代词

技术栈

  • • 后端: Python 3.12 + FastAPI + SQLAlchemy async
  • • 数据库: PostgreSQL 17 + pgvector
  • • 前端: Vanilla JS SPA (无框架, 12 视图)
  • • AI: OpenAI 兼容 API (gpt-4o + text-embedding-3-large)
