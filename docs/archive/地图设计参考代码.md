这份技术文档与代码参考严格遵循项目已落地的**垂直模块化架构（Vertical Slice Architecture）**与**少 Agent，强 Context**原则。在不改动现有 PostgreSQL 17 数据库结构（DDL）的前提下，通过业务逻辑层的“内存动态网络编译器”和基础图论算法，实现随着小说主线剧情推进而产生的动态地理拓扑演变。

## 第一部分：动态地理拓扑与旅行耗时计算服务设计文档

### 1. 模块定位与职责划分

本服务（`GeoTopologyService`）属于**事实层**的 `geo` 模块。

* **输入**：目标小说项目标识（`novel_id`）、起点（`source_id`）、终点（`target_id`）以及当前剧情所在的章节索引（`chapter_index`）。
* **计算核心**：打破传统静态地图的局限，引入“时空解耦查询”机制。通过动态覆写基础网络，计算在**特定剧情时间点**上最真实的路径连通状态与旅行时间。
* **输出**：两地在该章节是否连通、最短旅行耗时（小时）以及推荐的沿途区域节点链条。

### 2. 跨模块边界协作规则

根据系统通信规范，`geo` 模块严禁跨模块直接操作 `timeline_events` 表。

* `geo` 模块内部的 `GeoRepository` 负责提供基础、原始的静态路线数据（`geo_edges`）。
* 涉及主线剧情事件（如神战导致分割、两界融合等）对地理的破坏或修复，必须通过调用 **`TimelineFacade`** 提供的公开 API 薄层，获取在 `chapter_index` 之前所有生效的 `geo_effects` 脚本进行内存覆写。

### 3. 数据契约定义 (`geo_effects` JSON Schema)

在 `timeline_events` 表的 `geo_effects`（JSONB）字段中，动态事件的突变控制脚本需遵循以下标准 Schema 契约：

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "TimelineGeoEffects",
  "type": "object",
  "properties": {
    "edge_mutations": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["source_id", "target_id", "action"],
        "properties": {
          "source_id": { "type": "string", "format": "uuid" },
          "target_id": { "type": "string", "format": "uuid" },
          "action": { "type": "string", "enum": ["block", "connect", "reveal_hidden"] },
          "new_relation": { "type": "string" },
          "travel_time": { "type": "string" }
        }
      }
    }
  }
}

```

### 2. 业务逻辑层：`modules/geo/services.py`

动态图编译与 Dijkstra 路径核心搜索服务。由于不引入复杂的外部图数据库或 GIS 库，此服务完全采用纯拓扑图论实现。

```python
# modules/geo/services.py
import heapq
import logging
from uuid import UUID
from typing import Dict, List, Tuple, Optional, Any
from modules.geo.contracts import RouteCalculationResult

logger = logging.getLogger(__name__)

class GeoTopologyService:
    def __init__(self, geo_repo: Any, timeline_facade: Any):
        """
        通过依赖注入降低耦合
        :param geo_repo: geo模块的数据访问仓储层
        :param timeline_facade: timeline模块公开的通信Facade接口
        """
        self.geo_repo = geo_repo
        self.timeline_facade = timeline_facade

    def _parse_time_to_hours(self, travel_time_str: str) -> float:
        """解析多样化文本时间（如 '3天', '12小时'）为加权计算的标准浮点小时"""
        if not travel_time_str:
            return 1.0
        cleaned = travel_time_str.lower().strip()
        try:
            if 'd' in cleaned or '天' in cleaned:
                num = ''.join(c for c in cleaned if c.isdigit() or c == '.')
                return float(num) * 24.0
            if 'h' in cleaned or '小时' in cleaned:
                num = ''.join(c for c in cleaned if c.isdigit() or c == '.')
                return float(num)
            return float(cleaned)
        except ValueError:
            logger.warning(f"无法解析地理旅行耗时文本: {travel_time_str}, 采用默认兜底24小时")
            return 24.0

    async def _compile_active_graph(self, novel_id: UUID, chapter_index: int) -> Dict[str, List[Tuple[str, float]]]:
        """核心内存编译器：合并基础静态地理边与时间线主线突变脚本"""
        # 1. 获取基础静态路径
        static_edges = await self.geo_repo.get_edges_by_novel(novel_id)
        
        # 2. 内存注册表初始化 (排斥初始即为断绝状态的 blocked_path)
        edge_registry = {}
        for edge in static_edges:
            if edge.relation_type == "blocked_path":
                continue
            hours = self._parse_time_to_hours(edge.travel_time)
            edge_registry[(str(edge.source_location_id), str(edge.target_location_id))] = {
                "relation_type": edge.relation_type,
                "hours": hours
            }

        # 3. 跨模块契约调用：获取主线剧情截止当前章节生效的变动
        geo_effects = await self.timeline_facade.get_geo_effects_up_to_chapter(novel_id, chapter_index)
        
        # 4. 动态应用突变覆写 (Override 机制)
        for effect in geo_effects:
            mutations = effect.get("edge_mutations", [])
            for mut in mutations:
                key = (str(mut["source_id"]), str(mut["target_id"]))
                action = mut.get("action")
                
                if action == "block":
                    if key in edge_registry:
                        del edge_registry[key]
                elif action in ("connect", "reveal_hidden"):
                    hours = self._parse_time_to_hours(mut.get("travel_time", "12h"))
                    edge_registry[key] = {
                        "relation_type": mut.get("new_relation", "road_to"),
                        "hours": hours
                    }

        # 5. 编译为图论标准邻接表
        graph: Dict[str, List[Tuple[str, float]]] = {}
        for (src, tgt), info in edge_registry.items():
            if src not in graph:
                graph[src] = []
            graph[src].append((tgt, info["hours"]))
        return graph

    async def calculate_route(
        self, novel_id: UUID, source_id: UUID, target_id: UUID, chapter_index: int
    ) -> RouteCalculationResult:
        """对外公开的核心计算服务"""
        src_str = str(source_id)
        tgt_str = str(target_id)
        
        if src_str == tgt_str:
            return RouteCalculationResult(is_reachable=True, total_hours=0.0, path=[src_str])

        # 编译当前主线剧情进度下的专属拓扑网络
        graph = await self._compile_active_graph(novel_id, chapter_index)
        
        if src_str not in graph:
            return RouteCalculationResult(is_reachable=False, total_hours=float('inf'), reason="起点在当前章节无通路连通外部")

        # 基于优先队列的经典 Dijkstra 算法寻找最短时空开销路径
        queue: List[Tuple[float, str, List[str]]] = [(0.0, src_str, [src_str])]
        visited = set()
        
        while queue:
            (cost, current_node, path) = heapq.heappop(queue)
            
            if current_node in visited:
                continue
            visited.add(current_node)
            
            if current_node == tgt_str:
                return RouteCalculationResult(is_reachable=True, total_hours=cost, path=path)
                
            for (neighbor, edge_cost) in graph.get(current_node, []):
                if neighbor not in visited:
                    heapq.heappush(queue, (cost + edge_cost, neighbor, path + [neighbor]))
                    
        return RouteCalculationResult(is_reachable=False, total_hours=float('inf'), reason="受当前章节历史事件(如神战等)物理阻断，路线不通")

```

### 3. 外观模式层：`modules/geo/facade.py`

作为本模块公开暴露出给其他业务模块（如 `review` 审查模块或 `context` 模块）调用的薄层转发组件，禁止编写任何复杂的图论业务逻辑。

```python
# modules/geo/facade.py
from uuid import UUID
from modules.geo.contracts import RouteCalculationResult

class GeoFacade:
    def __init__(self, geo_topology_service):
        self._topology_service = geo_topology_service

    async def verify_character_movement(
        self, novel_id: UUID, from_location: UUID, to_location: UUID, current_chapter: int
    ) -> RouteCalculationResult:
        """
        供外部(如ReviewReport模型层)验证角色移动合法性的代理标准接口
        """
        return await self._topology_service.calculate_route(
            novel_id=novel_id,
            source_id=from_location,
            target_id=to_location,
            chapter_index=current_chapter
        )

```

# modules/geo/api.py
from fastapi import APIRouter, Depends, HTTPException, status
from pydantic import BaseModel, Field
from uuid import UUID
from typing import List
from core.dependencies import DbSession  # 假设为系统统一提供的会话上下文管理

router = APIRouter(prefix="/api/geo", tags=["Geographic Systems"])

class RouteQueryRequest(BaseModel):
    novel_id: UUID = Field(..., description="小说项目ID")
    source_location_id: UUID = Field(..., description="出发位置ID")
    target_location_id: UUID = Field(..., description="目的位置ID")
    chapter_index: int = Field(..., ge=1, description="当前写作/复查所在的章节数")

class RouteQueryResponse(BaseModel):
    is_reachable: bool
    total_travel_hours: float
    recommended_path: List[str]
    message: str

@router.post("/calculate-routing", response_model=RouteQueryResponse, status_code=status.HTTP_200_OK)
async def calculate_routing_api(request: RouteQueryRequest):
    """
    前端 vanilla JS (geoView.js) 在拉取时间滑块或者章节切换时，高频请求的动态路径连通测算接口
    """
    try:
        # 在应用初始化阶段，各Service实例通过容器或者依赖项已完成Facade绑定
        # 此处使用框架常规调用模拟
        geo_service = router.container.resolve_geo_topology_service() 
        
        result = await geo_service.calculate_route(
            novel_id=request.novel_id,
            source_id=request.source_location_id,
            target_id=request.target_location_id,
            chapter_index=request.chapter_index
        )
        
        return RouteQueryResponse(
            is_reachable=result.is_reachable,
            total_travel_hours=result.total_hours if result.is_reachable else -1.0,
            recommended_path=result.path,
            message=result.reason if not result.is_reachable else "主线演变计算完成，通道通畅"
        )
    except Exception as e:
        logger.error(f"路由测算API遇到未知内部错误: {str(e)}")
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, 
            detail="地理时空计算核心发生异常"
        )
