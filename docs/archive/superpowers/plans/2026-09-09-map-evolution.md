# 地图持续创作能力开发计划

目标：完成中级版本后的六个提升方向，优先保证作者操作流畅、资料可信、可修改与可恢复。
用户允许付费调用，图片使用 gpt-image；文本优先复用本机已验证 DeepSeek，备用连接只通过
应用支持的账户/项目运行时使用。诡秘验收项目及其正文、旧地图和图片是长期演示资产。

## 完成清单

- [x] 空间生成与图片辅助：站内明确选资料/地点，确认后生成空间候选；开发期图片由 Codex 的
  gpt-image 生成，经现有上传/候选比较/采用/校准流程进入地图。文本与图片调用分别记录，
  失败/恢复可理解，不要求为手工地图标记先写世界正史。
- [x] 可解释局部更新：字段级新旧值、差异定位、来源解释、历史版本预览；仅整理选定部分并保留
  手工布局。逐项采用必须连同依赖和来源验证，不能通过改 base ID 绕过过期 confirmation。
- [x] 写作双向联动：当前章节/场景找到地图地点，地图返回原文；草稿、光标、地图视角恢复。
  允许显式绑定已有世界地点；同名不自动合并，空态/多匹配/失败/晚到响应均有处理。
- [x] 空间与层级：城市、街区、街道连续编辑；沿街、入口、朝向等受限关系有类型校验和可视解释。
  保留“不按比例”，交叉不自动成为路口，已定位和手工控制点不被自动布置覆盖。
- [x] 图片长期一致：明确展示哪些校准点、空间内容发生变化；可比较旧图/新图与关联空间版本。
  相关图片保持候选、采用、私有读取和重新校准语义，不静默付费重画。
- [x] 轻量剧情排演：选择地点后突出资料明确的道路与经过顺序；缺少连接说明资料不足。
  排演与地图编辑/世界正史分开，不凭示意坐标推算路程、耗时或人物历史位置。
- [x] 交互贯穿：密集标签优先、选中可辨、平移/缩放自然、控制点编辑、返回位置恢复、键盘和窄屏。
- [x] 独立 review、修复、受影响测试/lint、跨栈完整门禁、真实浏览器及付费模型验收、文档与演示包。

## 实施批次

1. 空间层级/关系与写作查询 API；并行实现写作入口、地图差异/历史/定位恢复和轻量排演。
2. 现有地图标记进入确认后的关系提取、局部更新与安全采用；图片版本对照和校准影响说明。
3. 从站内资料到空间候选，再到 Codex gpt-image 图片及应用采用的真实流程验收；逐项补齐失败、
   恢复、密集/窄屏与演示材料。
4. 独立 review 修复后重新核验所有清单，不以已完成的子集重定义目标。

## 契约和风险

- World 继续拥有 map-atlas；跨模块只使用稳定接口。写作前端消费 owner/novel_id 保护的
  `GET /api/world/map-atlas/{novel_id}/map-links`，不访问 World ORM。
- 首批关系 enum 和可编辑层级为既有 JSON 文档的受限扩展，保留旧版本可读、恢复、CAS 与引用校验；
  无新数据库、队列、向量存储或自主 Agent 运行时，不需要新基础设施 ADR。
- 生成与局部采用必须重物化原 confirmation；排除/预算省略来源不能重新混入，陈旧来源失败关闭。
- 图片校准与内容覆盖分别解释，读者白名单和整图 hash 确认不因体验优化放宽。
- 本轮不实现完整故事时间轴/历史世界状态；它不是这六项中的轻量排演，需要独立领域设计。

## 产品与验证

目标画像为长期创作作者。预期收益是更快回忆空间、看清修改影响、继续写作；它仍是产品假设，
用诡秘项目的真实任务路径、首次成图时间、操作步数、返回恢复和失败可恢复性验证。
实现前 docs-check 已通过。每批先定向验证，集成后运行 `make test-ci TEST_WORKERS=2`，
涉及并发/持久化的路径用独立 PostgreSQL 测试库，真实诡秘库禁止自动测试清理。
最终运行 `make docs-check BASE_REF=origin/main`、diff 检查、浏览器验收并保留证据。

该决定不缩减来源、空间版本、图片对照、交互恢复与独立复核要求，不新增产品 Agent 运行时。
