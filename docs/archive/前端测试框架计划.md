# 前端测试框架迁移计划

## 选型

- **单元/集成测试**: Vitest + happy-dom
- **E2E 测试**: Playwright
- **模块系统**: ES Modules（逐步迁移）
- **事件绑定**: 内联 `onclick` → `addEventListener` + `data-action` 属性（逐步替换）

## 迁移阶段

### Phase 1: 基础设施搭建
1. `npm init` + `package.json`
2. 安装 vitest + happy-dom
3. `vitest.config.js`
4. test setup（happy-dom 环境 + 全局 mock）
5. 选最简单的视图（projectView）切 ESM + 写测试

### Phase 2: 视图逐个迁移
按需改造各视图，遵循：
- 加 `export`，去掉全局 `window.xxxView`
- 内联 `onclick` → `data-action` + `addEventListener`
- index.html 改 `<script type="module">` 或动态 import
- 每次改完同步添加测试

### Phase 3: Playwright E2E
- 安装 Playwright
- 起本地服务器 + 浏览器级测试
- 覆盖关键路径：登录项目 → 创建 → 各视图浏览
