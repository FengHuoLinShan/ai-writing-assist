## 阶段 1 — Alembic 迁移

### 目的
在一个迁移中完成所有 DDL 变更，确保原子性。

### 新建表（4 个）

#### 1.1 `core_entities` 表 — `world_entities` 改名
当前代码库中表名为 `world_entities`，在迁移中：
```sql
ALTER TABLE world_entities RENAME TO core_entities;
```

#### 1.2 `events` 表
```sql
CREATE TABLE events (
    entity_id UUID PRIMARY KEY REFERENCES core_entities(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES projects(id),
    source_chapter_id UUID NOT NULL REFERENCES imported_chapters(id) ON DELETE CASCADE,
    location_entity_id UUID NOT NULL REFERENCES core_entities(id) ON DELETE RESTRICT,
    timeline_order INTEGER NOT NULL,
    occurrence_time_label VARCHAR(100)
);
CREATE INDEX idx_events_timeline_order ON events(timeline_order);
```

#### 1.3 `entity_relations` 表
```sql
CREATE TABLE entity_relations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    novel_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    source_id UUID NOT NULL REFERENCES core_entities(id) ON DELETE CASCADE,
    target_id UUID NOT NULL REFERENCES core_entities(id) ON DELETE CASCADE,
    relation_type VARCHAR(64) NOT NULL,
    description TEXT,
    strength FLOAT NOT NULL DEFAULT 0.5,
    source_chapter_id UUID REFERENCES imported_chapters(id) ON DELETE SET NULL,
    caused_by_event_id UUID REFERENCES core_entities(id) ON DELETE SET NULL,
    quote TEXT,
    status VARCHAR(16) NOT NULL DEFAULT 'canonical',
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_entity_relations_source ON entity_relations(source_id);
CREATE INDEX idx_entity_relations_target ON entity_relations(target_id);
```

#### 1.4 `entity_revisions` 表
```sql
CREATE TABLE entity_revisions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    entity_id UUID NOT NULL REFERENCES core_entities(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    snapshot JSONB NOT NULL,
    source_chapter_id UUID REFERENCES imported_chapters(id) ON DELETE SET NULL,
    revision_reason VARCHAR(32) NOT NULL DEFAULT 'ai_import',
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_entity_revisions_entity ON entity_revisions(entity_id);
```

#### 1.5 `imported_chapters` 表
```sql
CREATE TABLE imported_chapters (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    novel_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    import_record_id UUID NOT NULL REFERENCES import_records(id) ON DELETE CASCADE,
    chapter_index INTEGER NOT NULL,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    is_analyzed BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_imported_chapters_novel ON imported_chapters(novel_id, chapter_index);
```

#### 1.6 characters 表列调整
```sql
ALTER TABLE characters DROP COLUMN id CASCADE;
ALTER TABLE characters RENAME COLUMN world_entity_id TO entity_id;
ALTER TABLE characters ADD PRIMARY KEY (entity_id);
ALTER TABLE characters ADD CONSTRAINT fk_characters_entity 
    FOREIGN KEY (entity_id) REFERENCES core_entities(id) ON DELETE CASCADE;
```

### 废弃表（drop）
```sql
DROP TABLE IF EXISTS timeline_events CASCADE;
DROP TABLE IF EXISTS relationships CASCADE;
DROP TABLE IF EXISTS entity_candidates CASCADE;
DROP TABLE IF EXISTS entity_aliases CASCADE;
```

### 输出文件
- `backend/alembic/versions/<hash>_v3_causal_spacetime_web.sql`

## 阶段 2 — world 模块 model 层

### 目的
重写 `models.py`，从"4 张独立表"升级为"core_entities + 3 扩展表 + 2 辅助表"。

### 当前
`backend/modules/world/models.py` — `WorldEntity`, `Relationship`, `EntityAlias`, `EntityCandidate`

### 目标 — 7 个 ORM 模型:

| 模型 | 表名 | 说明 |
|------|------|------|
| `CoreEntity` | `core_entities` | 统一核心实体（原 WorldEntity 改名，entity_type 自由字符串） |
| `Event` | `events` | 事件扩展表，entity_id PK+FK 1:1 绑定 |
| `EntityRelation` | `entity_relations` | 关系表（UUID 物理外键 + 追溯字段） |
| `EntityRevision` | `entity_revisions` | 快照版本表 |
| `Character` | `characters` | 人物扩展表（entity_id PK+FK） |
| `CharacterKnowledge` | `character_knowledge` | 知识边界 |
| `GeoLocation` | `geo_locations` | 保留不变（geo 模块持有，world 只 import） |

### 关键细节
- CoreEntity 新增 relationships: `event`/`character`/`geo_location`（uselist=False 1:1）+ `source_relations`/`target_relations`（1:N）
- Character 模型从 `character/models.py` 搬入：`world_entity_id` → `entity_id` PK+FK，移除独立 `id`
- CharacterKnowledge 搬入，补充 NovelMixin
- 废弃旧 `WorldEntity`、`Relationship`、`EntityAlias`、`EntityCandidate` 模型类

### 输出文件
- `backend/modules/world/models.py`（重写）

## 阶段 3 — world 模块 schema / contract 层

### 3.1 schemas.py 新增

**AI 提取契约:**
```python
class ExtractedEntity(BaseModel):
    entity_type: str          # 自由字符串
    name: str
    aliases: list[str]
    summary: Optional[str]
    content_json: dict

class ExtractedRelationship(BaseModel):
    source_name: str
    target_name: str
    relation_type: str       # 自由字符串
    description: Optional[str]
    quote: str               # 原文依据

class ExtractionOutput(BaseModel):
    entities: list[ExtractedEntity]
    relationships: list[ExtractedRelationship]
```

**CRUD Pydantic:** `CoreEntityCreate/Update/Response`、`EventCreate/Update/Response`、`EntityRelationCreate/Update/Response`、`RevisionListResponse`、`RollbackRequest`

`EventContext`、`EntityRelationContext`、`EntityRevisionContext` dataclass。搬入 `CharacterContext`、`CharacterContextBundle`、`CharacterKnowledgeContext`。

## 阶段 6 — imports 模块重构

### 目的
新增 `ImportedChapter` 模型，重构导入流水线为 `NovelSilentImportService`。

### 核心流水线
1. 取前 8000 字 → LLM 合成章节正则
2. `validate_and_compile_regex()` 四道门审计（语法→捕获组→ReDoS→冒烟测试）
3. 切分 → 批量写入 `imported_chapters`
4. 串行状态机：逐章 LLM 提取实体+关系（合并 Prompt）→ 直写 canonical + 打快照
5. global_memo 由 RAG 自动生成，作为上下文锚点传递

### 输出文件
- `backend/modules/imports/models.py`（追加 ImportedChapter）
- `backend/modules/imports/schemas.py`（追加）
- `backend/modules/imports/contracts.py`（追加）
- `backend/modules/imports/facade.py`（追加 execute_import_pipeline）
