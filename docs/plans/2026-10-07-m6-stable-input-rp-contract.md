# M6 契约：稳定输入与 RP 质量门禁

日期：2026-10-07。上游：[第一阶段计划](2026-10-06-world-foundation-phase1.md) §7.4。
独立复审确认：消息重排的短程布局对照不能证明整体 RP 质量不下降。生产保留原准备包位置；新的完整对照只评估已实施的检索、材料缓存与预算编译，原布局两臂相同。

## 1. 当前生产消息顺序

普通 `compile_story_messages` 的既有规则、长期约定、有效回顾、来源包、重抽信息、对话尾部及续写指令保持原顺序。Agent `preparation_packet_index` 返回 1，在首个 system 后插入准备包；准备包内容与围栏转义、权威优先级、最新用户输入、同一 `prepared.messages` 生成/审查均保持。

将 Agent 准备包放到最后一个 system 后的方案仅作为历史实验；旧短程结果不足且代理作者发现连续性反例，因此未采用。不能用消息多重集合相同或供应商缓存命中增加推断文学质量相同；以后若重提布局，须冻结新开发集/未使用留出并另行验证。

## 2. prompt 版本记录

Evidence `compile_interaction_story_context(prompt_name=…)` 缺省只记家族 `interaction-story`。Interaction 的 generation/agent_runtime/ensemble/ensemble_v2/proactive 五个调用方传 `STORY_PROMPT_VERSION`，与 attempt.usage 的 prompt_version 对齐。方法渲染版本与快照使用记录仍各自承担原职责。

## 3. 完整真实模型对照

`evals.rp_matrix` / `rp_source_families`：6 个开发来源族、3 个独立留出来源族，各 30 轮。来源事实分章，人物语气、规则、往事和保管证据不重复灌入每轮玩家输入；未来/他人秘密 canary 单独存放并验证不可见。

两臂使用独立生产 journey。基线固定 Git compiler 与 retrieval 文件，候选使用本次上下文链；同模型/参数，生产原消息布局。冻结实际来源/逐轮输入/裁判 rubric/harness/生产 Python 哈希。每次编译记录实际回读章、关键来源缺失、blocker 和 canary；新臂缺关键来源或泄漏即终止该尝试。

覆盖开场、30 轮普通发送、重抽、分支、第30轮真实 provider length 后同 attempt 续写，以及必需来源失效后的失败关闭与无故事释放。裁判在第1/5/10/20/30轮盲评：两臂各自历史随机排列，与输出顺序同步；分别评保真、人物声音、规则/资源、秘密/截止，严格 schema。

开发集质量与总费用门均通过才打开留出；holdout 标记在调用前写入，不能重置或根据留出调参。成本和质量分开报告，裁判费另列：生成/准备/审查/返修/续写/重抽/分支/失效的费用均计入对应臂，usage_unknown 按保留上界计，不把估计视为账单。

## 4. 预算与验收边界

用户已单独授权沿用现有 DeepSeek 账户与累计 USD 20；原调用、失败及未知用量不删除，硬帽不可调高。原 140 笔短程布局试验只作适配 smoke，不能核销完整开发/留出门。原始请求、输出与全账本只保存在仓库外私有目录；仓库只保存脱敏汇总、哈希、裁判与代理作者结论。

工程测试、合成 provider 浏览器和真实模型质量分别验收。主 Agent 代理作者验收已获用户授权，`human_validated=false`；须评阅实际输出而非仅转述裁判。未通过费用或质量门时保留失败与剩余工作，不能宣称 M0–M7 全部完成。

## 5. 本轮预算接续补充（2026-10-07，留出尚未使用）

依据主计划 §7.4 在累计 USD20 内重分配，共享普通调用上界 USD18，保留 USD2 失败额度；原累计账本、冻结文件、失败输出与费用均保留。只对已证实的原USD9发送前拒绝，以及已结算的空正文length，创建领域新尝试；成功轮次直接复用已保存结果。重抽须保留原拒绝引用，`continue` 不能用普通 `retry` 冒充。存在同轮未知收费、泄漏或其他质量失败时不自动重采样。

## 6. 评阅材料修正（2026-10-07，留出尚未使用）

开发生成及恢复已经完成；旧裁判只收到短局面摘要，将生成实际读取的第6/12章事实误认作新增设定。旧3判、空正文12000 token调用及全部费用保留，旧判标记为审核依据不完整。不能据此自动通过，也不能只重评失败项。

审核依据改为冻结起点前逐章完整原文（开发12章、留出36章），明确原文中的秘密不代表角色全部知情，排除第37章未来事实。来源和玩家输入哈希、独立历史与匿名顺序、四维system rubric均不变。各族审核原文及全部匿名评阅输入分别冻结哈希，原始freeze不覆盖；新评阅输入不能称为旧输入不变。

全部30个开发检查点统一重评，不重生成正文。单次上限24000 token；仅已结算、空正文、finish_reason=length三项同时成立时，以同一messages增至48000一次。有效质量失败或非空无效JSON不重评，未知收费阻断后续调用。按主计划§7.4在原累计USD20内重分配并逐笔预留，旧费用及本次裁判费都计入。来源失效必须证实source_context_blocked、零新付费调用及零故事释放，任意failed不算通过。

成本仍按原冻结门禁裁决；另列同一固定费率重算的事后比较，仅解释高峰/非高峰混杂，不替代原门禁或账单。开发质量或成本失败仍不打开留出，结果在整改报告记录。
