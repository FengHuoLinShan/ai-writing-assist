## 保留资产（不属于退役范围）

- 文件解析、章节识别、上传校验（`parsers.py`、`admission.py`）——Imports
  按计划保留的格式边界。
- 已验证的抽取 adapter、逐字证据校验、身份解析调用——迁为可调用步骤。
- `rollback_deep_import_delta_logs_by_workflow` 等历史审计路径。

## 已有的替代基础（不等于入口切换）

- 运行所有权/游标/预算：`evolution_runs`（E04）+ fencing（E06）。
- 窄提交与恢复：E03c freeze/apply/recover + T10/T11 故障注入。
- 推进顺序与屏障：E04 orchestrator + G2 纵切。
- 在途兼容分类：E07.d `compat.py` 只有分类骨架，尚无生产续接调用链。
- 入口适配：E07.e `legacy_adapter.py` 只有参数映射骨架；单 Scene handler 已注册，
  旧 API 尚未调用。另有显式启用的 `/api/evolution` 受控入口，已接完整现存 Scene 的
  范围确认、bootstrap/append、连续队列和免费恢复，也已接缺失 Scene 自动准备及
  Scene 后缀 revise/scoped_recompute，可由对象/已有观察定位起点。旧 API 现有世界对象、结构资产、
  覆盖和采用语义尚未等价；不能据此核销旧 API 替代。
