## 4. 项目助手与选区捕获现状（R00 事实底账）

- 捕获入口：`vue/bridge/index.js::getAssistantWorkContext` →
  `vue/shared/assistantContext.js::captureWorkContext`（writing 页取
  `#writing-editor` textarea 的 `selectionStart/End`，但**只取文本**
  `value.slice(start,end)`；DOM 选区页取 `selection.toString()`）。
- 会话链：`useProjectAssistant.send(context)` → `POST /api/assistant/
  sessions/{id}/runs`（TurnCreate：message + WorkContext + allow_web）。
- 服务端：`WorkContext`（`modules/assistant/schemas.py`）有 page/chapter/
  draft_id/source_hash/**selection 纯文本**/target/scope/时区/确认对；
  无 task_hint、无选区偏移。`AssistantService.execute` 把
  `work.model_dump_json()` 注入最终 user 消息（「当前工作位置」）。
- 前瞻链：`useForecast.focusFrom` 组装 focus（task_hint 恒取
  `context.task_hint || "unknown"`——**前端无任何设置点**）；契约
  `FocusRequest.selected_range: TextRange`（需 draft+hash）**前端从未发送**；
  服务端 `forecast/context.py` 按 selected_range 截取正文并做偏移校验。
- R00 断点结论：①选区无 SourceRange 语义（偏移+草稿绑定+服务端一致性
  校验缺失）；②task_hint/intent 全链缺失（turn 路径无字段、forecast 恒
  unknown，"只润色不主动扩大情节"无承载）；③forecast selected_range 未接。
