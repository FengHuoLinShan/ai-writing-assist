## 2. 入口副作用矩阵（T13 基线，I02 的整改输入）

"副作用"指写入正文/工作稿后必须发生的确定性后置动作：
章节索引重排（`evidence.request_chapter_index`）与
来源上下文失效（`evidence.mark_asset_context_changed`）。

| 入口 | 写入路径 | 章节索引 | 上下文失效 | 证据 |
|---|---|---|---|---|
| Writing API 创建/更新/采用 | `writing/api.py` 显式调用 | ✅ | ✅（API + 仓储层兜底） | api.py 4 处 `request_chapter_index`；`writing/repositories.py` `_changed/_created` 对工作稿统一 `mark_asset_context_changed` |
| 助手候选采用 | `writing/assistant_candidate_tools.py` | ✅ | ✅（仓储层兜底） | L198 显式 `request_chapter_index` |
| 助手新章/改写应用 | `writing/assistant_tools.py` `_new_apply`/revise → `WritingDraftService.create_draft_contract` | ❌ 缺 | ✅（仓储层兜底） | 该文件无 `request_chapter_index` 调用 |
| 创意对比采用 | `writing/creative.py` → `OPERATIONS["writing.revise"].apply` | ❌ 缺 | ✅（仓储层兜底） | 同上 |
| 协作采用（outbox 投递） | `collaboration/tasks.py` 事务性 outbox | ❌ 缺 | ✅（逐资产 `mark_asset_context_changed`） | tasks.py L27–49 |
| 作者确认（写作核对） | `writing/services.py` confirm 链 | N/A | ✅ | services.py L1610–1612 |
| 深度导入写入 | `imports/*`（经 Writing 适配） | ❌ 缺 | 部分（仅当走 Writing 仓储） | imports 模块无 `request_chapter_index` 调用 |

结论：上下文失效已在仓储层收敛；章节索引依赖每个入口自觉调用，
助手应用、创意采用、协作采用与导入四类入口缺失——同写工作稿不同副作用，
正是 T13 要暴露、I02（领域变更回执 + 确定性副作用投递）要消除的分叉。
G0 只记录不修：统一回执协议涉及 `writing/repositories.py`、协作 outbox
窄协议与各 adapter，属 E05/I02 范围。
