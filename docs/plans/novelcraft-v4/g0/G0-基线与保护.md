## 2. 入口副作用矩阵（T13 基线，I02 的整改输入）

"副作用"指写入正文/工作稿后必须发生的确定性后置动作：
章节索引重排（`evidence.request_chapter_index`）与
来源上下文失效（`evidence.mark_asset_context_changed`）。

| 入口 | 写入路径 | 章节索引 | 上下文失效 | 证据 |
|---|---|---|---|---|
| Writing API 创建/更新/采用 | `writing/api.py` 显式调用 | ✅ | ✅（API + 仓储层兜底） | api.py 4 处 `request_chapter_index`；`writing/repositories.py` `_changed/_created` 对工作稿统一 `mark_asset_context_changed` |
| 助手候选采用 | `writing/assistant_candidate_tools.py` | ✅ | ✅（仓储层兜底） | L198 显式 `request_chapter_index` |
| 助手新章/改写应用 | `writing/assistant_tools.py` `_new_apply`/revise → `WritingDraftService.create_draft_contract` | ✅（E02 轮已补齐） | ✅（仓储层兜底） | `_new_apply`/`_apply` 保存后显式 `request_chapter_index`；`writing/tests/test_assistant_side_effects.py` 断言 |
| 创意对比采用 | `writing/creative.py` → `OPERATIONS["writing.revise"].apply` | ✅（随 writing.revise 修复生效） | ✅（仓储层兜底） | 同上（creative 复用同一 operation） |
| 协作采用（outbox 投递） | `collaboration/tasks.py` 事务性 outbox | ❌ 缺（留 I02） | ✅（逐资产 `mark_asset_context_changed`） | tasks.py L27–49 |
| 作者确认（写作核对） | `writing/services.py` confirm 链 | N/A | ✅ | services.py L1610–1612 |
| 深度导入写入 | `imports/*`（经 Writing 适配） | ❌ 缺（留 I02） | 部分（仅当走 Writing 仓储） | imports 模块无 `request_chapter_index` 调用 |

结论：上下文失效已在仓储层收敛；章节索引原先依赖每个入口自觉调用。
E02 轮已把助手应用/创意采用两处对齐（复用 API 入口的同一显式调用与测试断言）；
协作采用与导入仍缺——统一领域变更回执（I02）落地时一并消除，届时本矩阵
的"显式调用"方案将被"确定性副作用投递"替代。

## 5. E02/E03a 增量（2026-09-21 第二轮）

- **E02 身份解析内核**（`backend/modules/evolution/identity.py`）：确定性裁决
  （唯一精确证据 → reuse；多个精确 → ambiguous 保持竞争；无精确 → new_candidate

  不支持则 unrelated。观察积累与身份解析分离：解析不改 observation_id、不吞观察。
  world 候选经 `facade.find_similar_entities` 结构适配（exact_* 归一为精确证据）。
