# NovelCraft 前端设计标准：现代简约

> 当前实现参考；回归验收以 [testing-guide.md](../../../testing-guide.md) 的前端重设计契约为准。本文的视觉参数、布局、组件分工和旧操作路径不构成兼容性门禁。2026-09-07 的全站重设计取代原三主题修复批次；架构决策见 [ADR-0019](../../adr/0019-local-theme-resource-packages.md)。

## 1. 用户与设计目标

作者需要安心继续创作、就地回看资料并控制采用；互动故事读者需要低负担开场、阅读和分支选择。两者使用独立外壳，共享视觉、明暗模式与主题资源。

用正文空间、清晰层级和渐进展开减少寻找与恢复成本。默认每个决定区域只有一个主操作；高级配置、批量管理、来源诊断和长历史按需进入。不要把 raw ID、JSON、Prompt/token、内部状态当作普通用户语言。

上述收益是产品假设；自动化验证只证明功能和可操作性，不代替真实用户喜好、重复使用与访谈。

## 2. 视觉系统

- 浅色：灰白底、白色内容面、石墨文字；深色：炭灰底、分层灰色面、柔和亮字。
- 主按钮、链接、选中和焦点使用蓝色；紫色表示 AI 与未采用候选，绿色表示已确认完成，橙色提示待决定或可恢复问题，红色用于阻断/保存保护失效。状态同时用文字或图标表达。
- 中文系统字体优先。界面正文 14–16px，说明至少 12px；写作和阅读默认 18px、1.85 行高，正文列约 680–760px。字号与用户正文字体偏好兼容。
- 间距采用 4/8/12/16/20/24/32/40/48px；控件圆角 8px，内容面与浮层约 12px。静态区域以留白、surface 和分隔线组织，投影用于浮层。
- 使用现有线性 SVG 图标；不将 emoji 当作业务导航图标。不保留便签、月亮、水墨水印和稿纸装饰。
- 装饰资源仅进入背景、正文纹理和空态固定区域；正文、控件、焦点与错误反馈不得隐藏或被资源阻挡。

## 3. 样式与主题所有权

| 层 | 职责 |
|---|---|
| `frontend-console/styles.css` | 字体与排版默认值、间距、结构、响应式布局和业务状态结构 |
| `frontend-console/editorial-theme.css` | `--nc-*` 颜色、语义别名、圆角、阴影和共享视觉；作者、RP、认证均消费此体系 |
| `frontend-console/vue/views/writing/writing-desk.css` | 写作布局细化、正文、版本和检查状态；只消费共享视觉变量 |
| `frontend-console/vue/theme/` | 主题配置校验、受限 ZIP 解压、资源加载和本地存储 |
| `frontend-console/vue/shell/composables/useTheme.js` | 当前外观、明暗选择、系统跟随、迁移、启动与资源释放 |

原 `--archive-*` 名称暂作为兼容转发，不再表达独立纸墨风格。RP 的 `--rp-*` 转发到共享语义变量，不保留独立固定调色板。重设计可调整内部 CSS 组织和变量，保持用户主题包的数据与安全契约。

持久化选择为 `light / dark / system`；解析后的 `data-theme` 为 `light / dark`。导入主题与明暗偏好分开，详细外部接口见 [主题包规范](theme-packages.md)。

## 4. 组件行为

| 组件 | 必须具备的状态与行为 |
|---|---|
| 按钮 | 主、次、文字、危险；hover、focus-visible、disabled、忙碌；保持忙碌标签，不重复提交 |
| 表单 | 可见标签、输入说明、就地错误、保存反馈；保留失败输入；原生 input/select/textarea 优先 |
| 搜索与筛选 | 首屏常用项、按需更多、明确结果数和清除方式；返回保留查询与位置 |
| 列表与卡片 | 主对象名称可打开，次操作菜单，状态／来源分层；单页仍显示总数，仅多页显示翻页按钮 |
| 页签 | 清楚选中态和程序化语义；不把刷新当前页面作为无意义动作 |
| 菜单 | 方向键和 Escape，选择后收起，焦点归还；工具进入忙碌态不妨碍菜单关闭 |
| 模态与抽屉 | 标题、背景 inert、焦点限制、Escape、原触发点恢复；嵌套确认复用现有模态机制 |
| 反馈 | 正常、首次、空态、加载、失败、冲突、成功；失败提供可执行下一步，不只显示日志 |
| 长任务 | 原位进度、停止／恢复、离开后续接；任务完成不等于作品内容自动采用 |

全页工作流工具复用 `WorkspaceToolCard` 与现有侧栏插槽；手机抽屉挂在 body 层，保留可见关闭入口。
复用 `ActionMenu`（侧栏使用可视视口内的浮层定位）、`useModalDialog`、`useLeaveGuard`、`OwnerAiDrawer`，手机上下文使用 `WorkspaceDrawer`。不为无额外行为的原生按钮和输入增加组件壳。

## 5. 布局与响应式

- 全局主要断点为 760px 与 1100px，少数内容组件保留必要微调。
- 作者主导航为写作、人物与世界、故事结构、地图、查找；作品切换独立，设置与管理为次级入口。桌面编辑正文时全局导航收为图标栏。
- 桌面写作：章节、正文、资料分区，正文拥有弹性空间；有场景资料时可直接展示资料栏，用户可独立收起并按作品记住选择。
- 手机直接使用完整正文编辑器；章节和资料通过模态抽屉进入。保留编辑标题、版本、保存、AI 建议和检查；不再要求先选速记／完整编辑模式。
- 作者手机底部导航不超过四项；考虑安全区和键盘。操作须在窄屏与键盘环境可完成，允许调整布局和滚动策略。
- RP 保留独立阅读列和输入区，分支、回顾与资料按需进入。进入设置后提供返回互动故事。

## 6. 可访问性与保护

必要文字与其表面对比度至少 4.5:1；控件可辨边界和焦点至少 3:1。触控目标应可实际命中，不以固定像素尺寸阻断重设计。允许浏览器缩放，尊重 reduced-motion。

主题、宽度和界面切换不丢失正文、选择和未保存输入；不要求保留同一 DOM 节点。切章、导航、晚到响应和账号变化继续执行现有隔离与恢复门禁。只有实际持久化成功才能显示已保存；服务端与本地备份同时失败时必须警示并保留离开保护。

## 7. 验证与展示

开发服务器打开 `/prototypes/design-system.html` 查看真实组件状态。主题资源示例从外观设置下载，支持预览、导入、导出和删除。

逐页验证首次进入、正常、空态、加载、失败／冲突、离开恢复及误操作保护；选择有代表性的窄屏/桌面、缩放、浅色/深色和资源主题完成用户任务，不冻结断点或尺寸。旧截图仅作历史参考，不要求像素比较或基线更新。

运行前端 lint、完整 Vitest、生产构建、受影响的功能 Playwright、文档门禁和 diff-check。测试须使用专用数据库及受限对象存储，不调用付费模型验证纯前端外观。

## 8. 独立全前端重设计预览（2026-09-12）

用户确认的下一版方向在 `/prototypes/redesign.html` 展示，默认进入写作页。它沿用 Vue 3 / Vite，
是独立的全前端视觉与本地交互演示，不是已经接回业务的新产品入口。现行产品和主题资源包保持原状。
启动前端开发服务后可直接访问，无需后端、账户、模型连接或数据库；刷新恢复虚构《潮汐来信》的示例。

### 视觉方向

结合 macOS 创作工具的精细层级，以及 iPhone / iPad 界面有意义的鲜亮色彩。
正文采用稳定的实色表面，控制层适度通透；系统字体、线性 SVG、紧凑工具栏和独立资料检查器
共同保护阅读节奏。作品封面、资料分类、故事线和地图标记可使用内容色彩，不与状态含义混淆。

| 颜色角色 | 表达 | 使用示例 |
|---|---|---|
| 蓝 | 操作、链接、当前选择与焦点 | 继续写作、选中章节、主要按钮 |
| 紫 | 灵感、AI 建议与尚未采用的候选 | 写作伙伴、建议比较 |
| 绿 | 已确认完成和创作进展 | 完成记录、成功反馈示例 |
| 橙 | 需要判断和可恢复问题 | 设定矛盾提醒、待决定事项 |
| 红 | 阻断风险与危险操作 | 版本覆盖冲突、破坏性操作确认 |

提醒同时使用文字/图标，解释问题、影响与下一步；一般提示就近轻量呈现，阻断事项才提高强调。
预览状态切换会清除旧提醒，不持续闪烁或呼吸。正文不因装饰色彩降低可读性。

### 动效与组件

悬停反馈约140ms、选择约220ms；菜单/对话框约160–220ms，抽屉约240ms。
按钮只压缩内部图形，外部命中区固定；分段选择使用一个连续指示器。开关、勾选和图标有短反馈；
输入文字、光标、数值和正文排版保持静态。专注/侧栏不逐帧改变正文宽度；资料出现时仅淡化。
主题短过渡表面颜色；提醒按状态出现一次，加载只在进行中转动，进度由明确示例值驱动。
使用CSS transition、Vue图标过渡、原生dialog与现有ActionMenu，不引入动效库。
局部内容更换复用很小的WAAPI淡化指令：同一区域只保留最新动画，切页/卸载/减少运动立即取消；
连续搜索输入不触发重复淡化，动画完成不承担保存或采用状态判断。资料/AI用非模态检查器，
创建与确认用模态；浮层开关始终保持内部布局。连续建议→比较返回原触发点，从面板外创建新任务时
捕获新的焦点来源。新建与计划面板默认聚焦名称，次要动作在左、主要动作在右。`prefers-reduced-motion` 关闭非必要动效，
`prefers-reduced-transparency` 使用实色；无 backdrop-filter 的浏览器保留完整实色路径。
组件展示页提供原速、快速反向和“减少动态效果”对照；系统减少运动优先，不能在预览中覆盖。
[逐项控件与动效验收](../../../.agent/tasks/2026/T-20260912-component-motion/CONTROL-INVENTORY.md)
覆盖原生声明、循环/条件实例及复用菜单；录屏只用于设计判断，不新增像素、结构或CSS写法门禁。

导航、页签、选择、主题与浮层可操作；保存、生成、采用、连接等只展示标明身份的示例反馈。
不加载正式账户/主题/业务状态，不调用 API、不使用持久存储。字体、图层和偏好表单当前仅展示控件，
不承诺影响真实正文或地图。全前端预览已扩展桌面、平板和手机收纳；正式功能、真实保存与恢复后续逐步接回，真实移动设备与软键盘验收单列。

### 第二轮独立评审后的文档界面

写作页以Pages/Notes的文档组织为主要参照：全站入口收进作品菜单，顶部合并文档工具组，
章节目录和本章资料按需出现；建议/比较打开时让出上下文面板空间，正文仍可阅读与操作。
专注不改变正文字号，保留阅读位置与退出焦点，不显示无法生效的侧栏开关。

高频页面使用简短对象标题。概览的待决定项采用鲜明橙色，内容封面承担作品色彩；
世界资料使用紧凑对象条目，详情展开后按可用空间改为单列。图标复用现有SVG并补齐
时间、专注、展开等缺项。阅读控制只保留返回、阅读设置、回顾与线索，维持独立行宽。
演示控制收进左下角小型展开入口；仍明确是虚构内容，业务未接回。

### 全前端扩展与会话连续性

原型按写作、世界资料、结构/场景、地图、查找、作品/计划、导入、写作伙伴、身份/设置、
旅程准备/阅读和组件展示组织。复杂状态在对应对象就近展开，不恢复成旧工具栏集合。
详情、候选、版本、目录导入、资料健康、关系图谱和处理记录均有明确入口。

`?page=writing&state=normal` 指定初始页面与状态；可选 `section`、`theme=dark`。
这些参数仅用于设计评审寻址，不存放文稿。Vue KeepAlive 保留本次页面输入和选择，外壳记住
返回入口与滚动；刷新恢复初始虚构示例，不连接 API、账户、数据库或浏览器持久存储。

标题/正文是本地编辑区域，输入时不由 Vue 回写内容；非工作稿有明确只读标识。
保存、备份失败、版本恢复、正式确认、候选采用和长任务由手动演示状态驱动；
演示身份随结果显示。候选来源变化或未通过审查不能演示为可采用，拒绝与关闭仍可操作。
采用到工作稿和作者确认正式正文分开；正式正文是作品内的稳定引用，不表示对外发布。

手机工作区使用底部快捷入口与全部工作区菜单；写作章节/资料收成模态抽屉，复用
`useModalDialog` 的背景隔离和焦点回还。窄屏比较按顺序阅读，图谱提供对象列表，地图提供名称
选择，不能要求拖动才能完成任务。系统减少运动始终优先，输入、焦点和正文不依赖动画完成。

## 9. 新设计的真实业务接入（2026-09-12，本地工作树）

独立原型继续作为无业务的设计对照；正式 `index.html` 的 Vue shell 与各业务 island 采用同一设计语言，复用原有 bridge、router、领域控制器和账户配置。原型的虚构数据、状态展示器和模拟成功不进入正式路径。

- 正文模式由作品工作区菜单导航，正文获得完整阅读宽度；章节和本章资料可收纳。标题在纸面直接编辑，保存工作稿就近可用，版本/正式正文确认收进菜单。保留可中断的操作和立即可见的键盘焦点。
- 作品、写作首页、计划、世界/故事/地图、查找、设置及互动入口使用各域的实际内容组织与语义色。控制层轻量，正文、证据、密集资料保持稳定实色。
- 正式保存/备份只认真实回执；新选择的章节同步当前 URL，刷新恢复同一章及适用本地备份。候选出现在版本选择中，但不能冒充工作稿；审查 `incomplete` 不显示通过，不解除采用门禁。
- 模型能力继续经过账户已验证连接与项目 owner 边界。任务进度来自后台回执，生成、独立审查、采用到工作稿、设为正式正文是不同结果。

实现与实际验收记录见 [业务接入任务](../../../.agent/tasks/2026/T-20260912-redesign-business-integration/TASK.md)。本地代码接入不表示提交、部署或物理移动设备验收已经完成。截图/录屏用于审美与操作判断，不新增像素、CSS 写法、固定布局或 DOM 门禁。
