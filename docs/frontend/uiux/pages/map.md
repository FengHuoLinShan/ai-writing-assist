# AI 地图册 UI/UX 执行规范

## 1. 页面定位

地图页服务需要管理长篇世界资料的项目 owner。核心任务是一次生成可浏览的地图册候选，随后按
自己的节奏采用，不把内部 ID、Prompt、token、对象 key 或审核队列心智模型暴露给作者。产品
价值仍是假设，使用 run/page 状态衡量首图等待、停止/恢复、采用、修改后采用和再次补全率。

## 2. 页面结构

- 首次进入：说明资料来源与 AI 补全边界，主按钮为“一键生成地图册”。
- 已有地图册：主按钮改为“补全/更新地图册”；完整重做放在次级入口。
- 生成中：展示实际计划页数、当前页和完成数，并提供“生成完当前页后停止”。
- 生成后：默认进入“本次生成结果”；“我的地图册”是独立页签，只显示已采用图片。
- 历史：`rejected`（不加入）只保留为不可恢复的历史；`deprecated`（移出地图册）可恢复。二者均不与当前候选或正式画廊混排。

作者选项只显示横版/方形、标准/精细、是否使用工作稿和是否生成室内图；默认横版标准映射为
`2048×1152 / medium / PNG`。没有图片连接时，主操作就地说明并提供进入设置的路径。
首次生成时设置直接展开；已有地图册时默认收起为作者可读摘要，需要修改时再展开。尚无任务和
地图页时不显示空的结果页签，避免作者在开始前先面对无内容的工作台。

## 3. 候选与正式图片

无旧图时展示候选大图；已有旧图时左右标明“地图册已有图片 / 新候选”，可同步缩放并切换
左侧旧图。候选区只出现“加入地图册”“不加入”“AI 修改/重生成”；旧图区的次级菜单才提供
“移出地图册”。采用成功固定提示“已增加，原有图片未改变”。同一地点的已采用页面组成画廊，
不自动替换。

每张候选固定呈现三类信息：

- 资料直接支持：可打开 Wiki、正文、设定、场景等原资料。
- AI 为画面补全：明确标注“不属于正式设定”。
- 存在冲突：允许修改和浏览，但采用前要求再次确认。

默认摘要只解释“为何这样画”，完整来源渐进展开。动态文本只使用 Vue 插值，不使用 `v-html`。

## 4. 层级、标注与编辑

层级树显示封面、世界、区域、城市、城区和街道；室内图默认关闭。正式地图册中无自身图片但
有已采用后代的祖先只作为目录，不显示虚假热点。父图标注只有在目标节点存在已采用图片时才
可跳转。

名称全部由前端标注层渲染，底图不烘焙文字。桌面端支持拖动归一化坐标和蒙版编辑；界面明确
说明蒙版边缘可能扩散。编辑、重生成和多参考图始终创建新候选，不修改来源图片。

## 5. 状态与误操作保护

必须覆盖：资料不足、缺少连接、规划失败、部分图片失败、moderation、权限/组织验证/额度/
限流、S3 失败、主动停止、刷新恢复、`provider_in_flight` 人工确认和全部拒绝。共同保证：已完成
候选不丢，原地图册不变。

移出地图册单独确认且可恢复；采用有资料冲突的候选需二次确认；刷新或离开页面后从服务端 run
恢复进度，不依赖活 DOM。加载、空态和错误都在当前操作区说明，并保留可执行的下一步。

上传地图使用共享 modal dialog 契约：打开后焦点进入文件控件，背景不可操作，Tab/Shift+Tab
留在对话框内；关闭按钮、遮罩和 Escape 共用未上传修改确认，关闭后恢复原触发按钮。上传中
这些关闭路径不可用，只能明确取消当前上传；失败保留图片、地图位置和名称供原位重试。卸载
工作台会中止上传、释放预览 Object URL 和 modal 背景租约，不改变上传 API 或候选审核 wire。

## 6. 响应式与可访问性

- `≥1280px`：层级导航、画布/对比区、来源与操作面板可并排。
- `901–1279px`：压缩侧栏，保留双图对比和同步缩放。
- `761–900px`：层级树、画布与对比图纵向排列。
- `≤760px`：允许浏览、采用和拒绝；不使用左右滑动决定，不提供精确拖动或蒙版编辑，并提示在桌面完成。

主操作使用原生按钮；页签、展开按钮、图片替代文本、加载状态和键盘焦点必须可读。触屏不把
拖动手势与采用/拒绝绑定，窄屏不产生横向页面溢出。页面文字、状态、弱表面和选中态只消费
三主题语义 token；图片视口保留中性深色校对画布，图上热点使用主题的高对比正反文字 token。
页签使用 2px accent 下划线；正文为 `--text-base`，辅助说明为 `--text-sm`，元数据为
`--text-xs`。`≤760px` 的页签、层级项、图片热点和展开入口命中高度至少 42px，390px 下操作组
可换行且长来源文字、文件控件不产生页面级横向溢出。

## 7. 验收

- `frontend-console/tests/vue/map/MapAtlasView.test.js` 覆盖候选/正式状态、比较、来源、冲突确认、停止恢复、上传对话框焦点/关闭/重试/卸载和独立页面操作；`editorialTheme.test.js` 与 `cssVariableContracts.test.js` 覆盖三主题对比、token、未定义变量和 390px 样式契约。
- 生产构建验证资源路径与 API contract。
- 一次性人工生图检查：无烘焙文字、跨层级地理连续、风格一致、主要地点覆盖、标注不遮挡、修改后仍形成新候选。
- 自动测试只使用固定 PNG 与 mock 服务，不产生费用；付费 live smoke 默认跳过。
