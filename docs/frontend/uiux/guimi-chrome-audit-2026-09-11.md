## 问题记录

### UX-001 · P2 · 地图默认布局让画布退到首屏下半部

- 类型：布局与操作效率；已观察，属于体验判断。
- 路径：侧栏“地图” → 我的地图册 → 阿霍瓦郡 · 地点索引。
- 实际：1570×875 下，画布从约 y=522 开始，只占约 534px 宽；下边缘超出首屏。外层导航、地图目录、选中对象表单并列，地图页却先展示大量工具与留白。
- 影响：想看地图全貌先要滚动或发现“专注看图”；默认编辑器难以看清空间关系。
- 期望：地图作为主工作区首屏完整可见，选中详情按需展开，工具栏更紧凑。保留专注模式，但不依赖它弥补默认布局。
- 证据：本任务 Chrome 地图首屏截图（会话内）；未测其他屏幕尺寸。

### UX-002 · P3 · 地图目录随层级缩进后标题碎裂

- 类型：可读性与视觉；已观察。
- 步骤：同 UX-001，查看四层目录。
- 实际：约 229px 的目录内，深层标题“水仙花街住宅 · 门前示意”折成三行，最末只剩“意”；区域标题也将“索引”拆开。层级标签和标题挤占同一行。
- 影响：四个地图条目就形成参差高度，难以扫读层级与地图名称。
- 期望：保证名称可读宽度，用可展开树或更浅缩进；避免末字孤行，完整名称仍可访问。
- 证据：同首屏截图。

### UX-003 · P2 · 结构警报的“查看”进入不可用检查记录

- 类型：功能入口断点；已复现。
- 路径：写作首页 → 进入正文编辑（第60章）→ 本章资料 → 警报。
- 步骤：点击“场景尚未完成人工复核”对应的“查看 →”；再试“场景尚未配置视角人物”的“查看 →”。

- 期望：直达对应场景及待处理字段；没有检查记录时说明并提供可执行动作。
