# 本机 Agent CLI 适配

作者可通过 `/api/local-agent` 为每个作品选择原账户模型连接或已配对 Mac 上的
Codex、Claude、Kimi、DSH、Pi CLI。
选择只作用于 Agent 任务；普通非 Agent LLM 步骤沿用项目账户连接。项目默认保持原连接。
范围包括助手、已登录 RP、前瞻、创作协作、连续性检查和场景排演中的人物意图 Agent。
CLI 的本机登录态不上传服务器，也不成为其他作者的统一凭据。

作者在 AI 能力页下载伴随程序并用十分钟配对码绑定作品。每个根任务单独确认本机权限后，
在线设备才领取；离线任务保持待处理。工作目录不限制 CLI 的主机权限，界面必须告知该
Mac 用户文件和命令可被访问。伴随进程只向服务器发出连接；服务器设备令牌只授权已绑定
项目及本轮注册工具，不接受 CLI 自选 owner、项目或任意业务写入。工具输出经原领域
schema、预算、确认和来源门禁。

运行由原 `async_tasks` 租约负责；本模块记录设备、invocation 与工具回执。原 task
停止、设备撤销、心跳超时或租约替换后拒绝迟到结果。已见文本可通过项目内回执读取，
用量/价格无法核对时显示未知。中断不会自动重放本机副作用；重新执行需作者显式新任务。
本机任务的异步恢复策略统一为 `never_retry`。

离线评测可显式使用 `evals.cli_executor.CLIStructuredExecutor`；既有严格隔离的
`CodexStructuredExecutor` 默认与现有评测命令保持不变。新执行器仅使用合成/明确授权的
输入，不能把旧评测结果直接与项目模型质量比较。
