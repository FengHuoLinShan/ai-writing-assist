# 协作与创作试验引擎 V2

作者通过 `/api/collaboration` 提出目标、必须保留的内容和可读取/试改的资料。
Case 的目标版本、Grant、每轮 InputManifest 与不可变 Artifact 分开保存。
一次请求只创建一个原任务队列执行身份；同目标同时只执行一轮，累计预算跨恢复保留。

## 数据与执行

运行将具体问题转换为有界工作图，支持按结果追加反证与试改。依赖失败收敛到不再变化；
`all_succeeded` 阻断后继，`all_terminal` 可保留部分成果作汇总。重复标题不是新证据。
规划器读取同一完整授权资料及已执行工作输入，不能靠重复字面查询消灭原文留白；
GraphDelta 的 capability 枚举按当前配方收窄。只有世界压力配方收到情境试验指令。
作者问题只阻断需要该决定的后续步骤，已安排的独立工作仍执行并保留部分成果。
主体投影由宿主决定；读者输入只含截止前正文，不含作者目标、计划或全知报告。

Workspace 将冻结来源与增量修订组成可见试改，保留删除覆盖。精确检查绑定全部字段、
目标、规则和查询集合。正文与试改原文超过可完整复核的上下文上限时明确拒绝缩略冒充。
“试改与比较”完整结束需要两种不同修改、各自检查与比较；缺项呈现为部分完成。

## 采用与恢复

采用前校验作者、novel_id、授权、来源集合、当前工作稿、修订摘要及最新检查。支持的
Writing/Story/World 修改经原操作 port，在同一个数据库事务写入，receipt/outbox 与变更
一同提交。原确认不能被新的材料或无关授权替代。UI 有未保存输入时禁止开始采用。

重新定位同一章节的新保存版本会创建新试改基线，保留原修订关联。三方比较自动保留
非重叠字段修改，重叠字段由作者明确选择；不会重新写回旧基线。撤回采用生成反向试改，
重验之后的人工编辑并重新检查，不删除采用回执。

## 与其他模块

Assistant 持有前瞻、处置和原领域批次；Interaction 持有旅程选中路径、私语、回顾与
角色观察状态；Story 持有排演观察与裁决协议；Evidence 持有授权资料与主体投影。
这些模块没有第二套 Canon、调度器或账户连接。运行时业务协作不授权开发工具子代理。

注册配方包括调查、试改、世界压力检查、盲读、专题研究和导入会诊。配方目录不等于
真实质量验收；每种配方的实际资料、工具、复核范围和遗漏应随运行记录给出。
开关默认关闭；真实模型对照、人工盲评与成本报告未通过前，不能据本地测试开启自动灰度。


## 资料、配方与共用试验

project 读取授权记录完整集合指纹；初始输入仍只载入所选资源。专项可在同一授权集合内
作有界字面补查，返回范围/hash 与实际遗漏。外部研究须独立授权，沿原公开检索/网页回读
和私有资料外发门禁，搜索摘要不当作事实；原网页回执可在恢复时复用。导入会诊只读精确
原组。custom_recipe 只能缩窄能力、保留原检查；不能授予新资料或新写入权限。

默认成员独立输入；single 策略在相同资料、预算、工作区和检查能力下共享本轮工作记录，
供有界顺序调查与公平对照。plan/member/check 可选择 owner 已验证的连接，统一用 Project
snapshot seam 获取当前轮换 Key，所有角色累计同一根预算。

盲读使用 Story ReadingNode：按章节和可选字符停点（合计最多八点）逐点解锁正文，先写
不可变认知与疑问，再读取下一段。读者不收作者目标/标题/计划；揭示只作后续对照。World
同情境重测与 Story observation_v2 的意图、观察、有限裁决、位置/物品/私有信念差量互不
冒充事实证明。RP 沿选中祖先恢复环境；首次 V2 只从正式选中叙述回读初态，行动对象解释
仍须出处复核，自称成功与未决动作不会直接成为成功事件。

## 自动跟进与恢复

follow_changes 默认关闭，开启后按原逻辑章节跟进已保存变化，45 秒稳定、十分钟冷却；
后台联网还须 allow_background_web。与原 Assistant review/forecast 共享 Watch、active_run
和日额度。AssistantRun 同 ID/task 的记录只是只读进度投影，不成为第二个执行根。

中断恢复保留成功产物、累计用量、未知回执和原截止时间；旧 lease/generation 不得回写。
授权到期、撤销或功能回退由 worker 维护停止未完成运行，已有回执和作者采用保持。
前端手改备份按项目/工作区保存，旧修订文字可显式找回；晚到响应有项目/目标 fence。
采用后仅在编辑器仍安全时载入服务器新版，新输入继续保留并显示冲突。

## 持久理解的保留与复用

作者显式开启 `Grant.retain_understanding` 后，完成的 author 调查可保留当前 succeeded 工作项
的已复核 claims；superseded 产物不能成为新理解。cognition head/commit/record 独立于运行保留期，
删除 run 不删理解，项目永久删除才级联清理。operation 请求摘要防重、head generation CAS 防并发，
无变化只追加 no_change 回执而不推进 head。重复结论保留仍有效的旧依赖，失效的旧依赖重查后才重绑，
避免同批结论互相淘汰。PostgreSQL 禁止改写回执和修订内容，只允许 is_current 从 true 退为 false。

每条理解保守继承整个 run 实际读集，包括规划与共享记录可能消费的产物资料、原始来源修订/hash、
上游认知引用、Evolution 已提交观察引用及负面查询范围。commit 同时保留实际作者目标、
约束与工作输入，明确为 author_retrospective，不能作为历史首次阅读证据。
新 case 经 Evidence 物化精确 cognition refs 后才进入实际 Prompt；
任一根来源排除、换版、作者修正或撤回都拒绝旧引用。无关 head 前进不替换已经冻结的引用。
选择最多 32 条且不超过完整 24000 字符复核容量；超额整条省略并记录覆盖，不截断后冒充完整。
历史未携带新字段的 Grant/InputManifest 保持原序列化指纹，可以恢复旧任务和盲读回执。

当前仅支持作者、完整本地域资料；显式历史截止、Scene 焦点、读者/角色、试改 overlay、
网页与导入会诊不复用作者回顾理解。正文前瞻只消费当前章之前的完整来源根，旧稿排除同时
排除该逻辑章节；生成与独立知识审查收到相同理解引用和原文来源映射。
作者纠正明确标为作者解释，不能继承旧 source_statement 的事实资格。次级界面支持历史、修正、撤回
确认、幂等重试和冲突保留输入；页内标签和路由离开同样保护未保存修正。不新增模型请求，不能把
工程来源新鲜或确定性复核替身当成真实语义质量验收。
