# NovelCraft 0.1.0-alpha.1

首个完整本地桌面预览版，提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。
内置数据库、后台任务与离线检索模型，无需 Docker 或另配服务器；图片保存在本机。
业务 AI 仍需在应用内配置并验证模型连接。

修复“交给编辑”成功后，就绪标记被后续编辑器通知偶发覆盖的问题。
修复 Mac 窗口应用被错误标为后台程序的问题；源码桌面模式不读取开发目录的 .env 配置。

系统要求：macOS 14+；Windows 10 1903+/11 x64。
Windows 缺少 WebView2 时安装器会自动补齐，此时需要联网。
首次启动需要初始化数据，请等待启动页面完成。

本版未正式签名/公证，系统可能提示来源未验证，仅供开发测试。
自动备份、恢复和跨设备同步尚未提供；没有旧开发库导入功能。
原生窗口、真实业务模型与作者使用验收的状态以发布时的验证记录为准。
