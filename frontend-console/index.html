帮助说明

欢迎使用小说创作控制台

这是一个面向中文长篇小说的结构化创作管理工具。

快速入门

  • 点击左侧菜单切换模块
  • 按 : 打开命令栏
  • 按 ? 查看所有快捷键

创作流程

  1. 创建项目
  2. 导入正文 → 世界对象自动抽取
  3. 查阅 RAG 知识索引
  4. 编译上下文 → 导出草稿
